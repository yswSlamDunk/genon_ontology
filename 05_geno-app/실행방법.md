# GenTology 띄우는 방법

데이터를 올려 온톨로지(스키마)를 직접 설계하고, 질문하고, 골든 질문으로 확인해 보는 로컬 시스템입니다.
**빈 상태로 시작합니다.** 같이 넣은 `업로드할_자료/`를 올린 뒤 화면의 예시를 눌러 가며 직접 구축해 보면 됩니다.
보험 실습 자료이고, 이름 · 주민번호 · 전화번호는 실습용으로 만든 가짜 값입니다.

## 1. 준비물 (처음 한 번)

- **Python 3.12 이상**
- **uv**: 파이썬 패키지 관리 도구입니다.
  - Mac: `brew install uv`
  - 그 밖의 OS: https://docs.astral.sh/uv/ 의 설치 안내를 따르세요.
- **OpenAI API 키**: AI 초안과 문서 읽기에 필요합니다. 없어도 직접 설계는 할 수 있습니다(3번 참고).

## 2. 띄우기

압축을 푼 폴더(`geno-app`)에서 터미널을 열고 아래 두 줄을 차례로 실행합니다.

```bash
uv sync
```

```bash
GENO_ENV=.env uv run uvicorn server:app --port 8795
```

- `uv sync`는 필요한 패키지를 `.venv` 폴더에 설치합니다(약 60MB, 처음 한 번만).
- 브라우저에서 http://localhost:8795/web/ 을 엽니다.
- 끌 때는 터미널에서 `Ctrl + C`를 누릅니다.
- 처음 띄우면 `data/` 폴더가 생기고, 올린 자료와 만든 온톨로지가 모두 거기에 저장됩니다.

## 3. AI 키 넣기

같은 폴더에 `.env` 파일을 만들고 본인 키를 넣은 뒤, 2번처럼 다시 띄우세요.

```
GEO_LLM_API_KEY=본인_키
GEO_LLM_MODEL=gpt-5.4-mini
```

- `GEO_LLM_MODEL`을 비우면 gpt-5.4-mini를 씁니다.
- OpenAI가 아닌 호환 서버를 쓰려면 `GEO_LLM_BASE_URL=주소`를 넣습니다.
- 키가 없으면 [AI 초안으로 시작]과 문서 읽기만 안 되고, 나머지 기능은 다 됩니다.

## 4. 구축해 보기

화면 첫 페이지의 **시작하기** 3단계를 따라가면 됩니다.

| 순서 | 하는 일 | 쓰는 자료 |
|---|---|---|
| ① 데이터 가져오기 | [데이터 가져오기 ▾] → 파일 업로드 → 파일을 끌어 놓고 [업로드] | `업로드할_자료/표_CSV/` 16개, `업로드할_자료/문서/` PDF 21개 |
| ② 엔터티 형식 · 관계 만들기 | [AI 초안으로 시작](키 필요)을 누르거나, [엔터티 형식 직접 추가]로 표를 골라 하나씩 만들고 관계를 잇습니다 | ①에서 올린 표 |
| ③ 골든 질문으로 확인 | 꼭 맞혀야 하는 질문과 정답을 넣고 돌려 봅니다 | |

- 화면 곳곳의 **"내 데이터로 만든 예시"** 칩(질문 · 규칙 · 메트릭 · 골든 질문)을 누르면 입력칸이 채워집니다. 막히면 이것부터 눌러 보세요.
- 위 오른쪽 [버전 기록]에서 이전 상태로 되돌릴 수 있습니다.

## 5. 알아 두면 좋은 것

| 하고 싶은 것 | 방법 |
|---|---|
| 처음부터 다시 | 띄운 상태에서 `curl -X POST localhost:8795/api/reset` (되돌릴 수 없음) |
| 다른 포트로 띄우기 | 명령의 `8795`를 다른 숫자로 바꿉니다 |
| 다 만든 모습 미리 보기 | `목업_예시화면.html`을 브라우저로 바로 엽니다(서버 필요 없음) |
| 자세한 화면 설명 | `README.md`. 다만 그 안의 경로(`~/Project/...`)는 만든 사람 컴퓨터 기준입니다 |

## 6. 안 될 때

- **`uv: command not found`**: 1번에서 uv를 먼저 설치하세요.
- **`address already in use`**: 8795 포트를 다른 프로그램이 쓰고 있습니다. 포트 숫자를 바꿔서 띄우세요.
- **AI 버튼이 잠겨 있거나 반응이 없음**: `.env`에 키가 들어 있는지, 띄울 때 명령 앞에 `GENO_ENV=.env`를 붙였는지 확인하세요.

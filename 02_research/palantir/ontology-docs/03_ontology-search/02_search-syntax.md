# 검색 문법 (Search syntax)

- 원문: https://www.palantir.com/docs/foundry/ontology/search-syntax/
- 사이드바 위치: Ontology search > Search syntax

이 페이지는 온톨로지(Ontology)에서 객체를 검색할 때 쓰는 문법, 특히 정규 표현식(regular expression) 검색 문법을 설명합니다. 온톨로지의 정규 표현식은 일반 프로그래밍 언어의 정규 표현식과 비슷하지만, 값 전체에 대해서만 일치를 검사하고 `^`, `$`를 지원하지 않는 등 차이가 있으므로 그 차이를 정확히 아는 것이 중요합니다.

이 페이지는 온톨로지에서 수행할 수 있는 여러 종류의 검색 문법을 설명합니다. 온톨로지 검색은 Workshop에서는 [필터 목록(filter list)](https://www.palantir.com/docs/foundry/workshop/widgets-filter-list/)으로, Object Explorer에서는 [검색창](../05_applications/01_object-explorer/03_search-and-explore-objects/01_search-objects.md)으로 할 수 있습니다.

<a id="regular-expression"></a>
## 정규 표현식 (Regular expression)

온톨로지의 정규 표현식(regex) 검색은 일반적인 정규 표현식과 비슷한 문법을 쓰지만 몇 가지 차이가 있습니다.

* 정규 표현식 검색을 하려면 문자열 속성(property)이 인덱싱(indexing)되어 있어야 합니다. 문자열 속성에 정규 표현식 검색을 사용하려면 Ontology Manager에서 해당 속성을 정규 표현식 검색용으로 인덱싱해야 합니다. 설정하려면 객체 타입의 **Properties** 탭으로 이동해 **Interaction** 탭을 선택한 다음 **Enable regex queries** 옵션을 선택합니다.
* 패턴은 부분 문자열이 아니라 값 전체와 일치해야 합니다. 인덱스가 문자열 전체를 분석하지 않은 단일 값으로 저장하기 때문에, 패턴은 항상 필드 값의 처음부터 끝까지 전체와 비교됩니다. 따라서 `cat`을 검색하면 정확히 `cat`인 값만 일치하고, `concatenate`처럼 `cat`을 포함하는 값은 일치하지 않습니다. 부분 문자열로 검색하려면 패턴 앞뒤에 `.*`를 붙입니다. 예를 들어 `.*cat.*`은 `cat`을 포함하는 모든 값과 일치합니다.
* `^`와 `$` 앵커는 지원하지 않습니다. 모든 일치 검사가 이미 암묵적으로 값의 처음에서 시작해 끝에서 끝나므로 이 앵커들은 불필요합니다.

**설명**: Python의 `re.search("cat", s)`는 문자열 어딘가에 `cat`이 있으면 일치로 판단하지만, `re.fullmatch("cat", s)`는 문자열 전체가 `cat`이어야 일치로 판단합니다. 온톨로지의 정규 표현식 검색은 항상 `fullmatch` 방식으로 동작한다고 이해하면 됩니다. 예를 들어 `name` 속성 값이 `cat`, `concatenate`, `Cat`인 객체 3개가 있을 때, 패턴 `cat`은 첫 번째 객체만, 패턴 `.*cat.*`은 첫 번째와 두 번째 객체를 찾습니다.

<a id="supported-operators"></a>
### 지원하는 연산자 (Supported operators)

* `.`는 임의의 문자 하나와 일치합니다.
  * `c.t`를 검색하면 `cat`, `cot`, `cut` 등과 일치합니다.
* `?`는 바로 앞 문자를 선택 사항으로 만듭니다(0번 또는 1번 일치).
  * `colou?r`를 검색하면 `color`와 `colour` 모두와 일치합니다.
* `+`는 바로 앞 문자를 1번 이상 반복합니다.
  * `go+d`를 검색하면 `god`, `good`, `goood` 등과 일치하지만 `gd`와는 일치하지 않습니다.
* `*`는 바로 앞 문자를 0번 이상 반복합니다.
  * `go*d`를 검색하면 `gd`, `god`, `good`, `goood` 등과 일치합니다.
* `{}`는 바로 앞 문자가 반복될 수 있는 최소 및 최대 횟수를 정합니다. `{2}`는 앞 문자가 정확히 2번 반복되어야 함을, `{2,}`는 최소 2번 반복되어야 함을, `{2,4}`는 2번 이상 4번 이하(양 끝 포함)로 반복되어야 함을 뜻합니다.
  * `go{2}d`를 검색하면 `good`과만 일치합니다. `go{2,4}d`를 검색하면 `good`, `goood`, `gooood`와 일치합니다.
* `|`는 OR 연산자로, 두 패턴 중 하나와 일치하게 합니다.
  * `cat|dog`를 검색하면 `cat` 또는 `dog`와 일치합니다.
* `()`는 표현식 안에서 그룹을 만들어, 연산자가 바로 앞 문자 하나가 아니라 그룹 전체에 적용되게 합니다.
  * `(un)?happy`를 검색하면 `happy`와 `unhappy` 모두와 일치합니다. `?`가 `un` 그룹 전체를 선택 사항으로 만들기 때문입니다.
* `[]`는 대괄호 안에 나열된 문자 중 하나와 일치합니다.
  * `gr[ae]y`를 검색하면 `gray`와 `grey` 모두와 일치합니다. `-`로 범위를 지정할 수 있으므로 `[a-z]`는 임의의 소문자, `[0-9]`는 임의의 숫자, `[A-Za-z]`는 대소문자 구분 없이 임의의 영문자와 일치합니다. 대괄호 안이 `^`로 시작하면 집합이 부정되므로 `[^0-9]`는 숫자가 아닌 임의의 문자와 일치합니다. `-`가 첫 번째 문자이거나 `\`로 이스케이프되면 문자 그대로의 대시로 취급됩니다.
* `"`는 문자열 리터럴 그룹을 만들어, 각 문자를 정규 표현식 연산자로 해석하지 않고 정확한 구문과 일치시킵니다.
  * `"v2.0"`을 검색하면 문자 그대로의 텍스트 `v2.0`과 일치합니다. 따옴표가 없으면 `.`가 와일드카드로 취급되어 `v2X0`이나 `v200`과도 일치할 수 있습니다.
* `\`는 이스케이프 문자로, 원래 연산자로 취급될 문자를 검색할 수 있게 합니다. 또한 다음과 같은 단축 문자 클래스를 제공합니다.
  * `\d`는 임의의 숫자(`0`\~`9`)와 일치합니다. `\D`는 숫자가 아닌 임의의 문자(문자, 문장 부호, 공백 등)와 일치합니다.
  * `\s`는 공백, 탭, 줄바꿈 같은 임의의 공백 문자와 일치합니다. `\S`는 공백 문자가 아닌 임의의 문자와 일치합니다.
  * `\w`는 임의의 단어 문자(영문자, 숫자, 밑줄: `a`\~`z`, `A`\~`Z`, `0`\~`9`, `_`)와 일치합니다. `\W`는 문장 부호, 공백 등 단어 문자가 아닌 임의의 문자와 일치합니다.
  * 예를 들어 `\d{3}-\d{4}`를 검색하면 `555-1234`나 `800-5678` 같은 패턴과 일치합니다. `\w+\s\w+`를 검색하면 `hello world`나 `John Smith`처럼 공백 하나로 구분된 두 단어와 일치합니다. 문자 그대로의 점을 검색하려면 `\.`를 사용합니다. 예를 들어 `example\.com`은 `example.com`과 일치하고 `exampleXcom`과는 일치하지 않습니다.

**설명**: 값 전체 일치 규칙과 연산자를 함께 쓰는 예를 보겠습니다. 전화번호 속성 값이 `555-1234`, `Tel 555-1234`, `5551234`인 객체 3개가 있다고 합시다. 패턴 `\d{3}-\d{4}`는 첫 번째 값만 찾습니다. 두 번째 값은 앞에 `Tel `이 붙어 있어 값 전체가 패턴과 일치하지 않기 때문입니다. 두 번째 값까지 찾으려면 `.*\d{3}-\d{4}`처럼 앞에 `.*`를 붙여야 합니다. 세 번째 값은 `-`가 없으므로 어느 패턴과도 일치하지 않습니다.

> **중간 요약**: 온톨로지의 정규 표현식 검색은 Ontology Manager에서 해당 문자열 속성의 정규 표현식 인덱싱을 켜야 쓸 수 있고, 항상 값 전체와 비교합니다. `. ? + * {} | () [] " \` 연산자와 `\d \s \w` 같은 단축 클래스를 지원하며, 부분 일치가 필요하면 `.*`로 앞뒤를 감쌉니다.

## 정리

- 온톨로지 검색은 Workshop의 필터 목록이나 Object Explorer의 검색창에서 사용합니다.
- 정규 표현식 검색을 쓰려면 Ontology Manager에서 문자열 속성의 **Enable regex queries** 옵션을 켜야 합니다.
- 패턴은 항상 값 전체와 비교되므로 `^`, `$`는 지원하지 않고, 부분 일치는 `.*패턴.*` 형태로 씁니다.
- 일반적인 정규 표현식 연산자(`.`, `?`, `+`, `*`, `{}`, `|`, `()`, `[]`, `\`)와 문자열 리터럴용 `"`를 지원합니다.

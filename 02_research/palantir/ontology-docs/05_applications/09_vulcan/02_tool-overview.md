# Vulcan 도구 (Tools)

- 원문: https://www.palantir.com/docs/foundry/vulcan/tool-overview/
- 사이드바 위치: Applications > Vulcan > Tools

이 페이지는 Vulcan에서 CAD 모델을 다루는 도구들(주석, 측정, 단면 평면, 메시 스타일, 부품 색칠, 부품 변환)을 하나씩 소개합니다. 어떤 도구의 결과가 온톨로지 객체로 저장되는지, 어떤 도구가 함수(function) 출력으로 구동되는지를 구분해 보면 Vulcan이 온톨로지와 어떻게 연결되는지 이해할 수 있습니다.

Vulcan은 CAD 모델에 주석을 달고, 측정하고, 단면을 보고, 스타일을 지정하고, 색을 칠하고, 위치를 바꾸는 도구를 제공합니다. 주석, 측정값, 단면 평면은 온톨로지 객체로 저장할 수 있고, 함수 출력은 부품 색칠과 변환을 구동합니다. Vulcan을 [Workshop 모듈에 임베드](04_widget.md#tools)할 때 각 도구를 표시하거나 숨길 수 있습니다.

*모든 스크린샷은 가상의 데이터를 사용합니다.*

<a id="annotations"></a>
## 주석 (Annotations)

**주석(Annotations)은** 부품의 특정 지점에 라벨, 본문 텍스트, 색으로 구분된 의도(intent)를 표시합니다. 다음을 표시하는 데 사용합니다.

* 검토가 필요한 설계 결함
* 수리가 필요한 고장 위치
* 품질 검사를 위한 관심 지점

![Vulcan 주석이 3D 모델의 한 부품에 붙어 있습니다.](https://www.palantir.com/docs/resources/foundry/vulcan/vulcan-tools-annotation.png)

<a id="measurements"></a>
## 측정 (Measurements)

**측정(Measurements)은** 모델 위 점들 사이의 거리를 기록해 물리적 크기 감각을 줍니다. 측정은 순서가 있는 점들의 집합이며, Vulcan은 그 점들이 정의하는 폴리라인(polyline)을 따라 잰 전체 거리를 보고합니다.

모델 형식이 물리 단위를 정의하고 있으면 Vulcan은 기본적으로 그 단위를 사용합니다. 장면 단위(scene units)는 모델 파일에 저장된, 단위가 없는 원시 좌표값입니다. 단위를 정하지 않는 형식의 경우, [CAD 객체](03_schema-reference.md#cad-object)에 `model_unit` 타입 클래스가 붙은 속성(property)이 없으면 Vulcan은 거리를 장면 단위로 보고합니다. 파일과 CAD 객체 모두 단위를 제공하지 않으면, **Measurement settings**의 **Scene units**로 현재 세션에 사용할 단위를 지정할 수 있습니다. 이 설정은 그 경우에만 나타나며, 페이지를 다시 불러오면 초기화됩니다.

![Vulcan에서 3D 모델 위 두 점 사이에 측정값이 표시되어 있습니다.](https://www.palantir.com/docs/resources/foundry/vulcan/vulcan-tools-measurement.png)

**설명**: 폴리라인은 점들을 순서대로 직선으로 이은 꺾은선입니다. 점 A, B, C를 찍으면 거리는 |AB| + |BC|입니다. 단위 문제의 예로, STL 파일에 좌표 `(0,0,0)`과 `(250,0,0)`이 있으면 파일만 보고는 250이 250mm인지 250m인지 알 수 없습니다. 이때 CAD 객체의 `model_unit` 속성이 `mm`이면 Vulcan은 250mm로 보고하고, 그런 정보가 전혀 없으면 단위 없는 "250"으로 보고합니다.

> **중간 요약**: 주석은 부품의 한 지점에 라벨과 의도 색을 붙이는 도구이고, 측정은 순서 있는 점들을 이은 꺾은선의 길이를 재는 도구입니다. 측정 단위는 파일, CAD 객체의 `model_unit` 속성, 세션 설정 순으로 정해집니다.

<a id="section-planes"></a>
## 단면 평면 (Section planes)

**단면 평면(section plane)은** 3D 공간에 배치된 평평한 평면입니다. 평면 한쪽의 형상을 숨겨 조립체(assembly) 내부를 볼 수 있게 합니다. 개별 부품을 숨기지 않고 내부 구성 요소를 검사할 때 단면 평면을 사용합니다. 예를 들어 하우징 안의 베어링 위치를 확인하거나, 기계 프레임을 통과하는 배선이나 배관 경로를 검토할 수 있습니다.

저장된 단면 평면은 위치와 방향을 저장하므로, 그 단면을 나중에 다시 불러오거나 세션과 사용자 사이에서 공유할 수 있습니다.

<a id="mesh-style"></a>
## 메시 스타일 (Mesh style)

**메시 스타일(Mesh style)은** 모델 형상이 렌더링되는 방식을 빠르게 바꿉니다. **Normal**(일반), **X-Ray**(투시), **Wireframe**(와이어프레임) 보기 사이에서 전환할 수 있습니다.

**설명**: Wireframe은 메시를 이루는 삼각형의 모서리만 선으로 그리는 방식이고, X-Ray는 표면을 반투명하게 그려 뒤쪽 부품이 비쳐 보이게 하는 방식입니다.

<a id="part-coloring"></a>
## 부품 색칠 (Part coloring)

**부품 색칠(Part coloring)은** 속성 값이나 함수 출력을 사용해 **Scene coloring**(장면 색칠)을 구동하며, 다음과 같은 데이터에 시각적 맥락을 제공합니다.

* 고장률
* 조달 리드타임(lead time)과 재고 수준
* 비용

**설명**: 예를 들어 부품별 고장률을 계산하는 함수가 `{ 부품A: 0.02, 부품B: 0.15 }`를 반환하면, 고장률이 높은 부품B를 빨간색으로, 낮은 부품A를 녹색으로 칠해 모델 전체에서 문제 부품이 어디에 있는지 한눈에 볼 수 있습니다.

<a id="part-transforms"></a>
## 부품 변환 (Part transforms)

**부품 변환(Part transforms)은** 함수 출력을 사용해 부품이나 조립체의 공간상 위치를 바꿉니다. 변환을 사용해 다음을 보여 줄 수 있습니다.

* 부품들이 서로 어떻게 맞물리는지
* 설치나 수리 중에 어떤 부품에 닿으려면 정비 장비를 어떻게 배치해야 하는지

> **중간 요약**: 단면 평면은 위치와 방향을 저장해 내부 단면을 공유하게 하고, 메시 스타일은 렌더링 방식을 바꿉니다. 부품 색칠은 속성이나 함수 출력으로 색을 칠하고, 부품 변환은 함수 출력으로 부품 위치를 옮깁니다.

## 정리

- 주석, 측정, 단면 평면은 온톨로지 객체로 저장할 수 있는 도구입니다.
- 측정은 폴리라인 전체 길이를 재며, 단위는 파일의 단위, CAD 객체의 `model_unit` 속성, 세션의 **Scene units** 설정 순으로 정해집니다.
- 메시 스타일은 Normal, X-Ray, Wireframe 렌더링을 전환합니다.
- 부품 색칠은 속성 또는 함수 출력으로, 부품 변환은 함수 출력으로 구동됩니다.
- Workshop에 임베드할 때 각 도구의 표시 여부를 정할 수 있습니다.

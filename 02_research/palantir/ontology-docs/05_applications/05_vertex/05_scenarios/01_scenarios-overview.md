# 시나리오 개요 (Overview)

- 원문: https://www.palantir.com/docs/foundry/vertex/scenarios-overview/
- 사이드바 위치: Applications > Vertex > Scenarios > Overview

이 페이지는 Vertex의 시나리오(scenario) 기능이 무엇이며, 이를 위해 Foundry에서 어떤 준비(모델, 모델 기반 함수, 시계열)가 필요한지 설명합니다. 시나리오는 "만약 ~라면?" 질문에 답하기 위해 입력 값을 바꿔 모델을 실행해 보는 기능입니다.

시나리오를 사용하면 모델링된 세계(modeled universe)와 상호작용하면서 "만약 ~라면(What if)" 질문을 던져 서로 다른 운영 조건을 시뮬레이션할 수 있습니다. 모델을 조직의 성과와 연결하는 Palantir의 상위 수준 접근법에 대해 더 알아보려면 [온톨로지의 모델(Models in the Ontology)](../../../01_ontology-building/03_models.md)을 참고하세요.

시나리오는 시스템 그래프를 대상으로 구성되며, 액션과 하나 이상의 모델링된 입력을 함께 평가하고 출력 값을 계산해 디지털 트윈(digital twin)의 현실 세계 상호작용을 반영합니다. Vertex의 통합 기능을 사용하면 여러 상호작용 집합을 모델링하고, 이것들을 자동으로 연쇄(chain)시켜 한 모델의 출력을 다른 모델의 입력으로 전달할 수 있습니다. 이를 통해 여러 시스템에 걸친 여러 프로세스를 이해하고 상호작용하면서, 제안된 변경이 처음부터 끝까지(end-to-end) 미치는 영향을 파악할 수 있습니다.

**설명**: 모델 연쇄를 입력과 출력으로 보면 다음과 같습니다. 모델 A가 "펌프 회전수"를 입력받아 "배관 유량"을 출력하고, 모델 B가 "배관 유량"을 입력받아 "탱크 수위"를 출력한다고 합시다. 펌프 회전수를 바꾸는 시나리오를 실행하면 A의 출력인 유량이 B의 입력으로 전달되어, 최종적으로 탱크 수위가 어떻게 달라지는지까지 한 번에 계산됩니다. 이는 함수 `B(A(x))`를 합성해 호출하는 것과 같은 구조입니다.

<a id="business-logic-and-models-in-foundry"></a>
## Foundry의 비즈니스 로직과 모델 (Business logic and models in Foundry)

운영 조건을 시뮬레이션하려면 먼저 그 조건과 조건들의 온톨로지상 관계, 기대되는 동작을 정의해야 합니다. 이는 [모델 기반 함수(Functions on models)](../../../02_define-ontologies/04_functions/14_models/01_functions-on-models.md)를 만들어 할 수 있으며, 여기서 Foundry 안의 모델을 바탕으로 비즈니스 로직을 작성하고 평가하고 배포할 수 있습니다.

모델은 미리 정의된 입력 집합을 받아 계산된 출력 집합을 돌려주는 작업(job)으로 생각하면 됩니다. 모델 버전은 입력 파라미터와 출력 파라미터를 지정하며, 시스템 그래프에 보이는 온톨로지 객체와 함께 구성할 수 있습니다. 이를 통해 모델링한 개념을 디지털 트윈과 긴밀하게 맞춰 동적인 시스템 상호작용을 제공할 수 있습니다. [Foundry의 머신러닝과 모델링에 대해 더 알아보세요.](https://www.palantir.com/docs/foundry/model-integration/overview/)

모델 기반 함수는 [액션으로 게시(published as actions)](../../../02_define-ontologies/03_action-types/11_function-backed-actions/02_function-actions-getting-started.md)되고 나면 Vertex에서 구성할 수 있게 되며, Vertex에서 시나리오를 상호작용 방식으로 실행해 잠재적인 운영 조건의 영향을 이해할 수 있습니다.

Foundry의 함수(Functions)를 사용하면 코드 작성자가 의사결정 과정을 돕기 위해 설계된 대시보드나 애플리케이션 같은 운영 환경에서 빠르게 실행될 수 있는 로직을 작성할 수 있습니다. 게시된 함수는 Vertex에서 동적인 시뮬레이션 사례 연구(simulated case study)를 지원하는 데에도 사용할 수 있습니다. [함수에 대해 더 알아보세요.](../../../02_define-ontologies/04_functions/01_overview.md)

> **중간 요약**: 시나리오를 실행하려면 먼저 모델과 그 모델을 감싼 함수를 만들고, 이를 액션으로 게시해 Vertex에서 쓸 수 있게 해야 합니다. 모델은 정해진 입력을 받아 출력을 계산하는 작업이며, 입력과 출력 파라미터를 온톨로지 객체와 연결해 둡니다.

<a id="time-series-for-scenarios"></a>
## 시나리오를 위한 시계열 (Time series for scenarios)

시간에 따른 시스템 변화를 이해하고 상호작용하려면, 측정값을 시계열 형태로 만들어 두는 것이 매우 중요합니다. 그래야 이를 모델의 입력으로 구성할 수 있고, 모델은 비교를 위해 계산된 시계열 출력을 생성합니다. 이를 통해 현재 상태를 모니터링하고, 과거 추세를 보고, 모델링된 조건에 시뮬레이션 재정의(override)를 적용해 미래 변화를 예측할 수 있습니다.

시계열 설정에 대한 더 많은 정보는 [시계열 문서](https://www.palantir.com/docs/foundry/time-series/time-series-overview/)에서 찾을 수 있습니다. 시계열과 관련해 추가 지원이 필요하면 Palantir 담당자에게 문의하세요.

> **중간 요약**: 측정값을 시계열로 준비해 두면 모델 입력으로 쓸 수 있고, 모델은 시계열 출력을 계산해 현재 상태, 과거 추세, 재정의를 적용한 미래 예측을 비교할 수 있게 해 줍니다.

## 정리

- 시나리오는 시스템 그래프 위에서 액션과 모델 입력을 바꿔 실행해 보는 "만약 ~라면" 시뮬레이션 기능입니다.
- 여러 모델을 연쇄해 한 모델의 출력을 다음 모델의 입력으로 넘기면 변경의 end-to-end 영향을 볼 수 있습니다.
- 모델은 모델 기반 함수로 감싸고 액션으로 게시해야 Vertex에서 사용할 수 있습니다.
- 측정값은 시계열로 준비해야 모델 입력으로 쓰고 시간에 따른 결과를 비교할 수 있습니다.

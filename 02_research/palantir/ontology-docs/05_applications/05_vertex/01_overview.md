# Vertex 개요 (Overview)

- 원문: https://www.palantir.com/docs/foundry/vertex/overview/
- 사이드바 위치: Applications > Vertex > Overview

이 페이지는 Foundry의 Vertex 애플리케이션이 무엇인지 소개합니다. Vertex는 온톨로지(Ontology)의 객체와 링크를 그래프로 시각화하고, 그 위에서 원인과 결과를 분석하고 시뮬레이션하는 도구입니다. 이후 Vertex 페이지들을 읽기 전에 Vertex가 해결하려는 문제를 파악하는 출발점입니다.

## Vertex

**Vertex**를 사용하면 실제 조직의 디지털 트윈(digital twin) 전반에서 원인과 결과를 시각화하고 정량화할 수 있습니다. Vertex 도구 모음을 사용해 조직이 선별해 게시한 기존 그래프에 접근해 탐색하거나, 새로운 시스템 그래프(system graph)를 만들 수 있습니다.

Vertex는 현재 상태, 예측된 상태, 제안된 상태를 바탕으로 데이터 기반 의사 결정을 돕는 도구로서, 조직의 성과를 극대화하도록 운영상의 의사 결정을 모니터링하고 시뮬레이션하고 최적화하는 도구 모음을 제공합니다.

Vertex는 다음과 같은 일을 도울 수 있습니다.

* 기능 부서별로 나뉜 사일로를 넘어 전체 네트워크의 실시간 뷰를 탐색해 **투명성을 확보합니다**.
* 주요 위험과 기회, 그리고 그것들이 목표에 어떤 영향을 주는지 중앙에서 알림을 받아 **중요한 것에 집중합니다**.
* 분석과 운영을 결합해 가장 영향력이 큰 변경 사항을 찾아 **미래를 시뮬레이션합니다**.
* 데이터 명확성과 모델 정확도를 높여 무엇이 효과가 있는지 확인하고 전역 최적(global optimum)을 향해 **학습하고 최적화합니다**.

![시스템 그래프](https://www.palantir.com/docs/resources/foundry/vertex/vertex_overview-system_graph.jpg)

*이 스크린샷은 가상의 데이터를 사용합니다.*

**설명**: 디지털 트윈은 현실의 조직(공장, 설비, 항공편, 공급망 등)을 데이터로 그대로 표현한 모델을 뜻합니다. Foundry에서는 온톨로지의 객체와 링크가 그 모델입니다. 그래프 자료구조 관점에서 Vertex의 그래프는 객체를 노드(node), 링크를 간선(edge)으로 그린 것입니다. 예를 들어 Airport 객체 2개와 Flight 객체 1개가 "출발 공항", "도착 공항" 링크로 연결되어 있으면 노드 3개, 간선 2개짜리 그래프가 됩니다. 시스템 그래프는 이런 노드와 간선으로 프로세스나 설비 사이의 흐름을 나타낸 그래프입니다.

## 정리

- Vertex는 온톨로지 객체를 그래프로 시각화해 조직 전체의 원인과 결과를 보여 주는 애플리케이션입니다.
- 기존에 게시된 그래프를 탐색하거나 새 시스템 그래프를 만들 수 있습니다.
- 모니터링, 시뮬레이션, 최적화를 통해 데이터 기반 운영 의사 결정을 지원합니다.

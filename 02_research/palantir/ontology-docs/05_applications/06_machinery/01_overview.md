# Machinery 개요 (Overview)

- 원문: https://www.palantir.com/docs/foundry/machinery/overview/
- 사이드바 위치: Applications > Machinery > Overview

이 페이지는 업무 프로세스를 모델링하고 관리하는 Machinery 애플리케이션을 소개합니다. 프로세스란 문서, 장비, 사람 같은 대상이 시간에 따라 상태를 바꿔 가는 흐름이며, Machinery는 이를 그래프로 표현해 비효율을 찾고 AIP 자동화를 조율하는 데 쓰입니다. 지원되는 워크플로와 대표 사용 사례가 함께 나옵니다.

많은 현실 세계의 사건은 비즈니스 워크플로, 정부 업무, 의료 절차처럼 프로세스(process)로 볼 수 있습니다. 프로세스에서는 문서, 장비, 개인 같은 엔터티가 시간에 따라 상태 변화를 겪습니다. Machinery 애플리케이션을 사용하면 프로세스의 모든 측면을 이해하고 관리하며, 원치 않는 동작을 찾아내고, 원하는 결과를 향해 개선할 수 있습니다. [AIP의 LLM 기반 기능](https://www.palantir.com/docs/foundry/logic/overview/)의 지원을 받아, Machinery를 여러 단계로 된 AIP 워크플로에서 여러 자동화를 조율하는 신뢰할 수 있는 프레임워크로 사용할 수 있습니다. 지원되는 워크플로는 다음과 같습니다.

* AIP와 자동화의 도움을 받아 프로세스 비효율 해결하기
* 여러 AI 에이전트를 조율해 AIP 사용 사례를 처음부터 끝까지 관리하기
* 외부 이벤트 로그로부터 진행 중인 프로세스를 마이닝(mining)해 기존 프로세스에 대한 가시성 확보하기
* 성과 지표와 기대치를 정의하고 모니터링해 프로세스 병목 찾기
* 실시간 사람 개입으로 AIP 워크플로를 감독하는 운영 애플리케이션 만들기

![프로세스 그래프 예시.](https://www.palantir.com/docs/resources/foundry/machinery/process-graph-example.png)

**설명**: 프로세스를 데이터로 보면 "객체 하나가 어떤 상태에서 어떤 상태로 언제 옮겨 갔는가"의 기록입니다. 예를 들어 보험 청구 객체 C1은 `접수(3/1) 다음 서류검토(3/2) 다음 승인(3/5)` 순으로 상태가 바뀝니다. 이런 상태들을 노드로, 상태 사이의 이동을 엣지로 그리면 위 이미지와 같은 프로세스 그래프가 됩니다. 프로세스 마이닝은 이런 이동 기록(이벤트 로그)을 대량으로 모아 실제로 어떤 경로가 자주 일어나는지 거꾸로 찾아내는 분석입니다.

## 사용 사례 (Use cases)

Machinery의 사용 사례와 워크플로 예시는 다음과 같습니다.

* **보험(Insurance):** 보험 청구의 처리 과정을 최초 접수부터 최종 결정까지 담아냅니다. 여기에는 관련 문서에 대한 OCR, 반자동 처리, 사람의 승인이 포함됩니다.
* **병원 운영(Hospital operations):** 환자가 병원 진료를 거치는 전 과정을 처음부터 끝까지 모델링합니다. 의료 문서 생성을 통해 운영을 지원합니다.
* **구매-지급(Purchase-to-pay):** 구매 요청부터 대금 지급까지의 조달 프로세스를 살펴보고 워크플로 효율을 높입니다.
* **주문-수금(Order-to-cash):** 주문 접수부터 대금 회수까지의 영업 프로세스를 최적화해 고객 만족과 현금 흐름을 개선합니다.

이런 프로세스 중 하나를 직접 모델링해 보려면 [Palantir Learning 포털 ↗](https://learn.palantir.com)의 ["Mining your first business process" 스피드런 과정 ↗](https://learn.palantir.com/speedrun-mining-your-first-business-process)을 완료해 보세요.

## 정리

- Machinery는 엔터티가 시간에 따라 상태를 바꾸는 프로세스를 이해하고 관리하고 개선하는 애플리케이션입니다.
- AIP 기능과 함께 여러 자동화와 AI 에이전트를 조율하는 프레임워크로 쓸 수 있습니다.
- 외부 이벤트 로그로 프로세스를 마이닝하고, 지표를 모니터링해 병목을 찾고, 사람이 감독하는 운영 애플리케이션을 만들 수 있습니다.
- 보험 청구, 병원 운영, 구매-지급, 주문-수금 등이 대표 사용 사례입니다.

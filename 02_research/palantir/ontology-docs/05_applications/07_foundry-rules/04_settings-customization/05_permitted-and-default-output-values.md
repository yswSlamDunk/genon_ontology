# 허용 값과 기본 출력 값 (Permitted and default output values)

- 원문: https://www.palantir.com/docs/foundry/foundry-rules/permitted-and-default-output-values/
- 사이드바 위치: Applications > Foundry Rules > Settings & customization > Permitted and default output values

이 페이지는 규칙 작성자가 규칙 출력의 각 필드에 넣을 수 있는 값을 제한하고 기본값을 지정하는 방법을 설명합니다. 필드마다 "열 값을 쓸 수 있는가, 직접 입력하는 정적 값을 쓸 수 있는가, 쓸 수 있다면 어떤 범위인가"를 정해 출력 데이터의 품질을 관리하는 기능입니다.

워크플로 출력은 워크플로 안의 모든 Foundry 규칙이 내보내는 결과의 목적지와 형식을 지정합니다. **rule editor**에서 각 규칙의 끝, 즉 **규칙 출력 [로직 블록](../02_core-concepts/04_rule-logic.md#logic-blocks)에서** 작성자는 각 워크플로 출력 필드에 열 또는 정적 값(static value)을 지정합니다. 값을 지정하면 필수 값인 경우 규칙 출력이 반드시 정의되고, 데이터가 올바른 데이터 타입으로 워크플로 출력 데이터셋에 안전하게 흘러 들어갈 수 있습니다.

**Permitted and default output values** 섹션을 사용하면 이 지정 과정을 간소화하고 규칙 출력 로직 블록을 더 세밀하게 사용자 정의할 수 있습니다. 기본값은 새 규칙이 만들어질 때 자동으로 지정되며, 열 값과 정적 값 중 하나를 고를 수 있는 옵션을 두 값 유형 중 하나만 허용하도록 제한할 수 있습니다.

![출력 필드 구성](https://www.palantir.com/docs/resources/foundry/foundry-rules/permitted_and_default_values_standard.png)

스크린샷은 표준 구성을 보여 주며, 이는 가장 허용 범위가 넓고 기본값을 지정하지 않은 구성입니다. 표준 구성에서 아무것도 바꾸지 않았다면 **Permitted and default output values** 섹션은 접힌 상태로 표시됩니다.

**설명**: "열 값"과 "정적 값"의 차이를 출력 열 `severity`로 예를 들면 다음과 같습니다. 열 값으로 지정하면 규칙 결과의 각 행에 있는 어떤 열(예: 입력 데이터의 `risk_level` 열)의 값이 행마다 그대로 들어갑니다. 정적 값으로 지정하면 규칙 작성자가 입력한 하나의 값(예: `high`)이 그 규칙이 내보내는 모든 행에 똑같이 들어갑니다. SQL로 보면 `SELECT risk_level AS severity`와 `SELECT 'high' AS severity`의 차이입니다.

<a id="behavior-and-example-use-case"></a>
## 동작과 사용 사례 예시 (Behavior and example use case)

각 출력 필드는 각자의 구성을 가질 수 있습니다. 다음 예시가 이를 가장 잘 보여 줍니다.

`equipment failure alert`(장비 고장 알림)가 특정 장비 항목으로 다시 연결되어야 한다면, 그 필드는 정적 값을 허용하지 않고(`None`) 객체 속성(property) `Serial Num`에서 파생된 열 값만 허용하도록 제한해야 합니다.

알림은 운영 워크플로의 핵심이므로 보통 어떤 프로세스와 연결됩니다. 장비 고장에는 어떤 형태든 수리가 필요하므로, 알림은 여러 가능한 상태 중 하나에 있을 수 있습니다. 워크플로 출력에는 `String` 타입의 필수 필드(2)인 `Repair Status` 필드(1)가 있습니다. 어떤 장비 고장은 알림과 함께 자동 정비 루틴이 실행되지만, 다른 고장은 수동 개입이 필요하다고 합시다. 이 정보는 규칙 작성자만 판단할 수 있으므로, 입력 데이터의 열 값은 비활성화됩니다(3, `None`). 상태는 여러 가능한 상태 중 하나(4)로 설정되어야 하며 기본값은 `Not started`여야 합니다. 규칙 작성자가 보게 되는 규칙 출력 로직 블록은 이 구성을 반영합니다. 정적 값과 열 값 사이의 전환 스위치가 비활성화되고, 가능한 모든 상태 옵션이 담긴 선택 메뉴가 표시됩니다.

![허용 값 구성 예시와 규칙 출력 블록](https://www.palantir.com/docs/resources/foundry/foundry-rules/permitted_and_default_values_example.png)

**설명**: 예시의 두 필드를 표로 정리하면 다음과 같습니다.

| 출력 필드 | 열 값 | 정적 값 | 기본값 | 이유 |
|---|---|---|---|---|
| `Serial Num` 연결 필드 | Selection(`Serial Num`만) | None | 없음 | 알림이 어느 장비에서 났는지는 데이터 행마다 달라야 함 |
| `Repair Status` | None | Selection(여러 상태) | `Not started` | 규칙 작성자가 규칙 단위로 정하는 값 |

> **중간 요약**: 출력 필드마다 허용할 값의 종류와 기본값을 따로 정할 수 있으며, 그 구성에 맞춰 규칙 작성자가 보는 출력 폼(스위치, 선택 메뉴 등)이 바뀝니다.

<a id="configuration-options"></a>
## 구성 옵션 (Configuration options)

구성은 열 값과 정적 값의 두 섹션으로 나뉩니다. 두 섹션 모두 출력 필드 타입에 따라 달라집니다. 구성이 불완전하거나 만족될 수 없으면 오류 아이콘이 문제를 표시합니다. 규칙 작성자가 요구 범위를 벗어난 정수처럼 규칙에 맞지 않는 값을 넣으면, 같은 오류 아이콘이 규칙 출력 로직 블록에도 문제를 표시합니다.
`String` 타입 출력 값에는 필드를 문자열 템플릿(string template)으로 만드는 옵션이 있습니다. 문자열 템플릿은 정적 값과 열 값을 조합한 것입니다. **Field is a string template** 옵션을 선택하면 다른 구성은 더 이상 할 수 없습니다.

![문자열 템플릿 필드가 있는 Rule editor](https://www.palantir.com/docs/resources/foundry/foundry-rules/string_template_rule_editor.png)

**설명**: 문자열 템플릿은 고정 문자열 사이에 열 값을 끼워 넣는 형식입니다. 예를 들어 "장비 " + `Serial Num` 열 + " 온도 초과"처럼 구성하면 행마다 "장비 SN-001 온도 초과", "장비 SN-042 온도 초과" 같은 서로 다른 문자열이 만들어집니다. 프로그래밍 언어의 문자열 보간(예: Python의 f-string)과 같은 개념입니다.

<a id="column-values"></a>
### 열 값 (Column values)

열 값은 규칙 로직이 적용된 뒤 기반 데이터셋의 열에서 나오는 값을 말합니다. 규칙 작성자가 규칙 로직을 쓸 때는 실제 데이터를 알 수 없으므로, 출력 열은 타입이나 입력 속성 이름으로만 제한할 수 있습니다. 열 값에는 다음 옵션을 구성할 수 있습니다.

* **Any:** 기존의 어떤 열이든 이 출력 필드에 지정할 수 있습니다.
* **None:** 이 출력 필드는 정적 값만 받습니다. 열 참조는 허용되지 않습니다.
* **Selection:** 지정된 열 옵션 집합 중 어떤 열이든 이 필드에 지정할 수 있습니다.

<a id="static-values"></a>
### 정적 값 (Static values)

정적 값은 규칙 작성자가 규칙을 만들거나 편집할 때 직접 입력하는 값을 말합니다. 이 값을 숫자나 날짜 범위 안에 있도록 제한하거나, 여러 값을 받는 입력이 올바른 길이를 갖도록 제한할 수 있습니다. 사용자 입력과 값 선택 입력은 드롭다운 메뉴로 표시되므로 규칙 작성자가 올바른 값을 더 쉽게 입력할 수 있습니다. 정적 값에는 다음 옵션을 구성할 수 있습니다.

* **Any:** 필드 타입에 맞는 어떤 값이든 이 출력 필드에 지정할 수 있습니다.
* **None:** 이 출력 필드는 열 참조만 받습니다. 정적 값은 허용되지 않습니다.
* **Selection:** 지정된 값 집합 중 어떤 값이든 이 출력 필드에 지정할 수 있습니다. 선택적으로 다른 값도 허용할 수 있습니다. 옵션은 레이블로 표시됩니다.
* **Range:** 지정된 범위 안의 정적 값만 허용됩니다. 이 옵션은 숫자 타입과 날짜 타입에서만 사용할 수 있습니다.
* **Users:** 지정된 Foundry 사용자 집합 중 어떤 사용자든 이 필드에 지정할 수 있습니다. 사용자를 하나도 고르지 않으면 제한이 적용되지 않습니다. 이 옵션은 문자열 타입에서만 사용할 수 있습니다.

**여러 값을 허용하는** 타입에서는 제한이 입력의 각 항목에 적용됩니다. 예를 들어 입력의 각 정수가 요구 범위 안에 있어야 하고, 각 사용자가 미리 선택된 사용자 중 하나여야 하며, 각 항목이 레이블이 붙은 선택 항목 중 하나여야 합니다.

> **중간 요약**: 열 값은 Any, None, Selection으로, 정적 값은 Any, None, Selection, Range(숫자와 날짜), Users(문자열)로 제한할 수 있습니다. String 필드는 문자열 템플릿으로 만들 수도 있으며, 다중 값 타입에서는 제한이 항목마다 적용됩니다.

## 정리

- 규칙 출력의 각 필드에는 열 값 또는 정적 값을 지정하며, 이 섹션에서 허용 범위와 기본값을 정합니다.
- 표준 구성은 모든 것을 허용하고 기본값이 없으며, 이 경우 섹션은 접혀 있습니다.
- 열 값 옵션은 Any, None, Selection이고, 정적 값 옵션은 Any, None, Selection, Range, Users입니다.
- 구성 오류나 규칙 작성자의 잘못된 입력은 오류 아이콘으로 표시됩니다.
- String 필드는 정적 값과 열 값을 조합하는 문자열 템플릿으로 만들 수 있습니다.

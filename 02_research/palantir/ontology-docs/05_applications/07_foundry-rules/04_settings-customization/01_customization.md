# Foundry Rules 사용자 정의 개요 (Overview)

- 원문: https://www.palantir.com/docs/foundry/foundry-rules/customization/
- 사이드바 위치: Applications > Foundry Rules > Settings & customization > Overview

이 페이지는 기본 배포 구성을 넘어 Foundry Rules 워크플로를 특정 사용 사례에 맞게 바꾸는 방법들을 모아 둔 목차입니다. 이어지는 페이지에서 각 사용자 정의 방법을 자세히 다룹니다.

[Foundry Rules 배포](../03_deploy/01_deploy-foundry-rules.md) 문서에 설명된 기본 구성은 모든 Foundry Rules 배포에 일반적으로 적용되도록 설계되었습니다. 하지만 Foundry Rules 워크플로를 여러분의 구체적인 사용 사례에 맞게 추가로 조정하고 싶을 수 있습니다.

Foundry Rules를 사용자 정의하는 일반적인 방법은 다음과 같습니다.

* [선택 기능 활성화](02_enable-optional-features.md)
* [사용자 정의 속성(property) 추가](03_add-a-custom-property.md)
* [규칙 편집 권한 설정](04_rule-permissions.md)
* [허용 값과 기본 출력 값](05_permitted-and-default-output-values.md)
* [Foundry Rules 파이프라인 사용자 정의](06_customize-foundry-rules-pipeline.md)

## 정리

- 기본 배포 구성은 범용이며, 사용 사례에 맞게 추가 조정할 수 있습니다.
- 대표적인 사용자 정의는 선택 기능 활성화, 사용자 정의 속성 추가, 편집 권한 설정, 출력 값 제한, 파이프라인 사용자 정의입니다.

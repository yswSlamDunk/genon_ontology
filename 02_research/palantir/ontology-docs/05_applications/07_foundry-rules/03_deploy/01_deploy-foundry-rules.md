# Foundry Rules 배포 개요 (Overview)

- 원문: https://www.palantir.com/docs/foundry/foundry-rules/deploy-foundry-rules/
- 사이드바 위치: Applications > Foundry Rules > Deploy > Overview

이 페이지는 Foundry Rules를 처음 배포하는 전체 절차를 안내하는 개요입니다. 템플릿 배포, 워크플로 구성, 규칙 작성 및 실행의 세 단계와 각 단계의 예상 소요 시간, 그리고 관련 문서로 가는 링크를 제공합니다.

Foundry Rules를 배포한다는 것은 각 [구성 요소](../02_core-concepts/01_core-concepts.md), 구체적으로 Workshop 애플리케이션, 백킹 객체와 액션(Action), Foundry Rules 워크플로 구성을 배포하는 것을 말합니다. 먼저 템플릿을 배포하고, 다음으로 워크플로를 구성한 뒤, 마지막으로 규칙을 작성하고 실행합니다. 전체 배포에 예상되는 시간은 약 30분입니다. 각 단계는 아래 문서에서 설명합니다.

1. [워크플로 템플릿 배포:](02_deploy-workflow.md) <em class="bp3-text-muted"> 예상 시간 약 3분</em>
2. [워크플로 구성:](03_configure-workflow.md) <em class="bp3-text-muted"> 예상 시간 약 10분</em>
3. [규칙 작성 및 실행:](04_author-and-run-a-rule.md) <em class="bp3-text-muted"> 예상 시간 약 10분</em>

배포 중 문제가 생기면 [문제 해결 참고 자료](../07_common-issues.md) 페이지를 확인하세요.

Foundry Rules 제품을 수정하는 방법(예: 선택 기능 활성화, 사용자 정의 속성(property) 추가, 편집자 권한 변경)은 [Foundry Rules 사용자 정의](../04_settings-customization/01_customization.md) 페이지를 확인하세요.

2022년 7월 이전에는 Foundry Rules(이전 이름 Taurus)에 사용자가 직접 작성하는 트랜스폼을 포함해 더 많은 구성이 필요했습니다. 이 시점 이전에 Foundry Rules를 배포했다면 해당 [구성과 개념](../06_legacy-foundry-rules-setup-taurus/01_legacy-foundry-rules-setup-taurus.md)에 대해 더 알아보세요.

## 정리

- Foundry Rules 배포는 Workshop 애플리케이션, 백킹 객체와 액션, 워크플로 구성을 함께 배포하는 작업입니다.
- 절차는 템플릿 배포(약 3분), 워크플로 구성(약 10분), 규칙 작성 및 실행(약 10분)의 세 단계이며 전체 약 30분이 걸립니다.
- 문제 해결, 사용자 정의, 2022년 7월 이전의 레거시(Taurus) 설정은 각각 별도 페이지에서 다룹니다.

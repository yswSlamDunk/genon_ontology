# 객체에 댓글 달기 (Comment on objects)

- 원문: https://www.palantir.com/docs/foundry/object-views/comment-on-objects/
- 사이드바 위치: Applications > Object Views > Comment on objects

이 페이지는 Object View에서 객체 하나에 댓글을 남기는 기능을 소개합니다. 여러 사람이 같은 객체를 두고 협업할 때 의견, 멘션, 첨부 파일을 객체에 직접 붙여 둘 수 있습니다.

여러 사용자가 특정 객체 하나를 함께 다루는 경우가 많습니다. 이런 협업을 돕기 위해 Object Explorer에서는 사용자가 객체에 댓글을 달고, 다른 사용자를 멘션하고, 파일과 이미지를 첨부할 수 있습니다.

어떤 Object View에서든 헤더의 **View comments** 버튼을 사용해 해당 객체의 Comments Helper를 열 수 있습니다.

![댓글](https://www.palantir.com/docs/resources/foundry/object-views/comments_in_helper.png)

Object Explorer에서 객체에 다는 댓글은 [Workshop의 Comment 위젯](https://www.palantir.com/docs/foundry/workshop/widgets-comments/)과 관련이 *없습니다*.

**설명**: 댓글은 특정 객체 인스턴스(예: 기본 키가 `F100`인 Flight 객체)에 붙습니다. Workshop의 Comment 위젯은 별개의 기능이므로, 한쪽에 남긴 댓글이 다른 쪽에 자동으로 보인다고 가정하면 안 됩니다.

## 정리

- Object View 헤더의 **View comments** 버튼으로 객체별 Comments Helper를 엽니다.
- 댓글에서 다른 사용자를 멘션하고 파일과 이미지를 첨부할 수 있습니다.
- 이 댓글 기능은 Workshop의 Comment 위젯과 서로 관련이 없습니다.

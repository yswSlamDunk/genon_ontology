# 스케줄 레이어(퍽) 스타일 지정 (Schedule layer (puck) styling)

- 원문: https://www.palantir.com/docs/foundry/dynamic-scheduling/scheduling-schedule-layer-style/
- 사이드바 위치: Applications > Dynamic Scheduling > Schedule layer (puck) styling

이 페이지는 Scheduling Gantt Chart 위젯에서 일정 객체를 그리는 막대, 즉 "퍽(puck)"의 모양을 바꾸는 세 가지 방법(퍽 스타일, 색상, 표시 속성)을 설명합니다. 같은 일정 데이터라도 퍽을 얇게, 배경으로, 또는 한 시점의 표식으로 그리면 사용자가 정보를 읽는 방식이 달라지므로, 화면 설계에서 중요한 설정입니다.

스케줄 레이어는 기본적으로 간트 차트 위에 "퍽"으로 렌더링됩니다. 이 퍽은 워크플로의 서로 다른 개념을 나타낼 수 있고, 맞춤 설정을 통해 다양한 동적 시각화를 만들 수 있습니다.

**설명**: 스케줄 레이어(schedule layer)는 간트 차트에 겹쳐 그리는 데이터의 한 층으로, 보통 객체 타입 하나(예: 정비 작업)의 객체 집합(object set)을 그립니다. 퍽은 그 객체 하나하나를 시작 시각부터 종료 시각까지의 가로 막대로 그린 것입니다.

스케줄 레이어(또는 "퍽")의 모양을 맞춤 설정하는 방법은 세 가지입니다.

1. **Puck Style**
2. **Coloring**
3. **Properties**

**Puck style**을 선택해 스케줄 레이어에 있는 퍽의 시각적 표현을 바꿀 수도 있습니다.

<a id="1-puck-style"></a><a id="puck-style"></a>
## 1. 퍽 스타일 (Puck style)

**Puck style**을 선택하면 레이어에 있는 퍽의 시각적 표현을 바꿀 수 있습니다. 구성할 수 있는 퍽 스타일은 세 가지입니다.

<img src="https://www.palantir.com/docs/resources/foundry/dynamic-scheduling/schedule-layer-styling-2.png" alt="스케줄 레이어 스타일 지정 예시." width="700" >

* **Standard:**
  * Standard 스타일은 간트 차트에 마우스로 상호작용할 수 있는 직사각형 퍽을 렌더링합니다.
  * 선택적으로 퍽 높이를 지정해 퍽의 두께를 정할 수 있습니다. 이 값은 Workshop 변수로 뒷받침되므로, 이 변수를 최종 사용자에게 노출해 필요할 때 퍽 높이를 바꿀 수 있게 할 수도 있습니다.
  * 퍽 높이의 일반적인 용도는 다음과 같습니다.
    * "얇은" 퍽으로 시간에 따른 상태를 표현합니다.
    * "얇은" 퍽으로 덜 중요하거나 보조적인 정보 묶음을 표현합니다.
    * "두꺼운" 퍽으로 해당 이벤트에 대한 정보 "카드"를 표현합니다.

* **Background:**
  * Background 스타일은 간트 차트에 마우스로 상호작용할 수 없는, 약간 투명한 퍽을 렌더링합니다.
  * Background 퍽은 규칙(Rules)을 지원하지 않습니다.
  * Background 퍽의 일반적인 용도는 다음과 같습니다.
    * Background 퍽으로 가용성을 표현합니다(예: 초록색과 빨간색으로 색상 구분).
    * Background 퍽으로 단계나 상태를 표현합니다.
    * Background 퍽으로 선호도를 표현합니다.

* **Event:**
  * Event 스타일은 간트 차트에 시간 범위가 아닌 단일 타임스탬프를 나타내는 특정 시점 표식을 렌더링합니다.
  * Event 퍽은 드래그 앤 드롭이나 규칙(Rules)을 지원하지 않습니다.
  * 다음 옵션을 사용할 수 있습니다.
    * **Is global:** 활성화하면 이벤트가 차트의 모든 행에 걸쳐 표시됩니다.
    * **Always open:** 활성화하면 이벤트 플래그가 항상 펼쳐진 상태로 표시됩니다.
    * **Icon:** 표준 아이콘을 선택하거나, Media Reference 속성으로 뒷받침되는 사용자 지정 아이콘을 선택합니다.

**설명**: 세 스타일을 데이터 관점에서 보면 다음과 같이 구분됩니다. Standard는 시작과 종료가 있는 구간 데이터를 사용자가 직접 옮기고 편집하는 용도이고, Background는 같은 구간 데이터를 참고용 배경(예: 정비사 근무 가능 시간)으로만 보여 주는 용도이며, Event는 시각 하나만 있는 데이터(예: 점검 마감 시각)를 표시하는 용도입니다. 여기서 Workshop 변수는 Workshop 모듈 안에서 위젯끼리 값을 공유하는 상태 값입니다.

> **중간 요약**: 퍽 스타일은 Standard(상호작용 가능한 직사각형, 높이 조절 가능), Background(상호작용 불가, 반투명, 가용성이나 단계 표시용), Event(단일 시점 표식) 세 가지입니다.

<a id="2-coloring"></a><a id="coloring"></a>
## 2. 색상 지정 (Coloring)

각 스케줄 레이어마다 색상 정의를 지정할 수 있습니다. 옵션에는 **Static**, **Segmented by**, **Conditional** 색상 지정이 있습니다.

**설명**: Static은 레이어 전체를 한 색으로, Segmented by는 특정 속성 값(예: 작업 유형)마다 다른 색으로, Conditional은 조건식(예: 지연 여부가 참이면 빨간색)에 따라 색을 정하는 방식으로 이해할 수 있습니다.

<a id="3-properties"></a><a id="properties"></a>
## 3. 속성 (Properties)

각 스케줄 레이어에 대해, 퍽 위에 직접 표시하거나 팝오버 카드에 표시할 온톨로지 속성을 정의할 수 있습니다.

* 팝오버 속성(Popover properties):
  * 스케줄 레이어의 객체, 그 객체에 링크된 객체에서 속성을 선택하거나, 함수 기반 속성(function-backed property)을 사용합니다.
  * 표시 이름을 바꾸거나 제거하도록 선택할 수 있습니다. 속성 서식은 Ontology Manager에서 속성 구성과 함께 설정합니다.
  * 이 속성들은 팝오버 카드에 나타납니다. 팝오버 카드는 퍽 위에 마우스를 올렸을 때 나타납니다.

* 퍽 속성(Puck properties):
  * 스케줄 레이어의 객체, 그 객체에 링크된 객체에서 속성을 선택하거나, 함수 기반 속성을 사용합니다.
  * 표시 이름을 바꾸거나 제거하도록 선택할 수 있습니다. 속성 서식은 Ontology Manager에서 속성 구성과 함께 설정합니다.
  * 이 속성들은 퍽 위에 직접 나타납니다. 선택한 속성이 퍽에 모두 들어가지 않으면, 위에서 설명한 **Puck styling > Standard > Variable height** 옵션으로 퍽 높이를 조정해야 할 수도 있습니다.

**설명**: 함수 기반 속성은 데이터셋 열에 저장된 값이 아니라 함수(function)가 실행 시점에 계산해서 돌려주는 값입니다. 예를 들어 "남은 작업 시간"처럼 저장해 두지 않은 값을 퍽에 표시할 때 사용합니다.

> **중간 요약**: 색상은 Static, Segmented by, Conditional 중에서 고르고, 표시할 속성은 마우스를 올렸을 때 뜨는 팝오버 카드용과 퍽 위에 바로 쓰는 퍽 속성용으로 따로 지정합니다.

## 정리

- 스케줄 레이어의 객체는 간트 차트에 "퍽"으로 그려지며, 퍽 스타일, 색상, 속성 세 가지로 모양을 바꿀 수 있습니다.
- Standard 퍽은 상호작용과 높이 조절이 가능하고, Background 퍽은 반투명하며 상호작용과 규칙을 지원하지 않고, Event 퍽은 단일 시점을 표시하며 드래그 앤 드롭과 규칙을 지원하지 않습니다.
- 색상은 Static, Segmented by, Conditional 방식으로 지정합니다.
- 속성은 팝오버 카드와 퍽 위 두 곳에 따로 지정하며, 링크된 객체의 속성이나 함수 기반 속성도 쓸 수 있고 서식은 Ontology Manager에서 정합니다.

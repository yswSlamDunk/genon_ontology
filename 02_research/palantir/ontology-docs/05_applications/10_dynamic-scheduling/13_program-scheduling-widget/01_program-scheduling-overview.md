# Program Scheduling 위젯 개요 (Overview)

- 원문: https://www.palantir.com/docs/foundry/dynamic-scheduling/program-scheduling-overview/
- 사이드바 위치: Applications > Dynamic Scheduling > Program Scheduling widget > Overview

이 페이지는 프로그램, 프로젝트, 작업을 시간순 타임라인으로 보여 주는 Workshop 위젯인 Program Scheduling을 소개합니다. Scheduling Gantt Chart가 자원(행)에 일정을 배정하는 데 초점을 둔다면, 이 위젯은 작업을 프로젝트나 단계별로 묶어 보여 주고 작업 사이의 선후 관계(의존성)를 화살표로 그려 진행 상황과 병목을 파악하는 데 초점을 둡니다. 퍽 종류, 의존성 표시 방식, 화면 구성을 다룹니다.

**Program Scheduling** 위젯은 프로그램, 프로젝트, 작업을 시간순으로 보여 주는 Workshop 위젯입니다. 여러 업무 흐름(workstream)에 걸친 진행 상황을 추적하고, 작업들이 서로 어떻게 연결되는지 시각화하며, 하위 산출물에 영향을 줄 수 있는 병목(blocker)을 찾는 데 사용합니다. 이 위젯은 시작 시각과 종료 시각을 나타내는 날짜(date) 또는 타임스탬프(timestamp) 속성(property)을 가진 모든 객체 타입과 함께 동작합니다.

Program Scheduling 위젯을 구성하는 모듈 빌더는 다음을 할 수 있습니다.

* 대화형 타임라인에서 프로젝트와 작업 진행 상황을 추적합니다. 작업은 예정된 기간을 반영하는 퍽(puck)으로 표시됩니다.
* 작업 의존성을 퍽 사이의 화살표로 시각화해, 사용자가 병목을 쉽게 찾고 지연이 프로그램 전체로 어떻게 연쇄되는지 이해할 수 있게 합니다.
* 타임라인 옆에 접고 펼 수 있는 그룹으로 이루어진 계층형 표로 작업을 정리합니다(예: 프로젝트, 팀, 단계별로 묶기).

아래 예에서 Program Scheduling 위젯은 프로젝트 단계별로 묶인 작업을 보여 주며, 의존성 화살표가 산출물 사이의 관계를 강조합니다.

<a id="puck-types"></a>
## 퍽 종류 (Puck types)

데이터 레이어의 각 작업이나 이벤트는 타임라인에 **퍽**으로 렌더링됩니다. 퍽 종류는 레이어마다 구성하며, 항목이 어떻게 시각화되고 어떤 상호작용이 가능한지를 결정합니다.

* **Standard 퍽:** 시간 범위에 걸친 작업이나 활동을 나타내는 직사각형 막대입니다. 작업 사이의 의존성을 시각화하는 의존성 화살표를 지원합니다.
* **Background 퍽:** 프로젝트 단계, 계획 주기, 검토 기간처럼 더 넓은 시간 구간을 나타내는 음영 처리된 직사각형 영역입니다. Background 퍽은 그 앞에 놓인 작업들에 시각적 맥락을 제공하지만, 읽기 전용이므로 사용자가 편집할 수 없습니다.
* **Event 퍽:** 단일 시점에 놓이는 얇은 세로 표식입니다. 마일스톤, 마감일, 주요 의사결정 시점을 나타낼 수 있습니다.

> **중간 요약**: Program Scheduling 위젯은 작업을 시간순으로 보여 주고 의존성과 병목을 시각화하는 위젯이며, 퍽은 Standard(기간 작업, 의존성 화살표 지원), Background(넓은 기간, 읽기 전용), Event(단일 시점) 세 종류입니다.

<a id="dependencies"></a>
## 의존성 (Dependencies)

Program Scheduling 위젯은 작업 의존성을 타임라인 위의 관련 퍽들을 잇는 화살표로 시각화할 수 있습니다. 이를 통해 사용자는 순서 제약을 이해하고 어떤 작업이 하위 작업을 막고 있는지 찾을 수 있습니다. 의존성은 레이어마다 구성하며, 같은 레이어에 있는 다른 객체들의 기본 키(primary key)를 참조하는 객체 타입의 배열(array) 속성을 선택해 지정합니다.

* 의존성 화살표는 Standard 퍽에서만 사용할 수 있습니다.
* 퍽 위에 마우스를 올리면 그 퍽의 의존성 사슬이 강조되므로, 어떤 작업이 막혀 있고 어떤 작업이 다른 작업을 막고 있는지 추적하기 쉬워집니다.
* **Hide arrows by default** 인터페이스 옵션으로 화살표를 기본적으로 숨길 수 있습니다. 사용자는 실행 중에 화살표 표시 여부를 전환할 수 있습니다.

**설명**: 의존성 속성은 각 작업 객체에 "먼저 끝나야 하는 작업들의 기본 키 목록"을 배열로 저장하는 방식입니다. 예시 데이터는 다음과 같습니다.

| task_id | name | depends_on |
|---|---|---|
| T1 | 설계 | [] |
| T2 | 구현 | ["T1"] |
| T3 | 테스트 | ["T2"] |

이 경우 화살표는 T1에서 T2로, T2에서 T3로 그려집니다. 자료구조로 보면 작업이 정점이고 `depends_on`이 간선인 방향 그래프입니다. T1이 늦어지면 T2와 T3가 연쇄적으로 밀린다는 것을 화살표를 따라가며 확인할 수 있습니다.

> **중간 요약**: 의존성은 같은 레이어 객체들의 기본 키를 담은 배열 속성으로 지정하며, Standard 퍽 사이의 화살표로 표시됩니다. 마우스를 올리면 의존성 사슬이 강조되고, 화살표는 기본적으로 숨길 수도 있습니다.

<a id="widget-layout"></a>
## 위젯 화면 구성 (Widget layout)

아래 그림은 위젯 전체 화면 구성을 보여 줍니다.

<img src="https://www.palantir.com/docs/resources/foundry/dynamic-scheduling/scheduling-table-layout.png" alt="Program Scheduling 위젯 화면 구성 개요." width="1000" >

1. **Timeline(타임라인):** 위젯 본문에는 구성 가능한 시작 및 종료 타임스탬프로 제어되는 가로 시간축을 따라 작업 퍽이 배치됩니다. 편집한 내용이 있으면 오른쪽에 **Save Changes** 버튼이 나타납니다.
2. **Rows(행):** 본문 왼쪽에는 프로젝트, 팀, 단계 같은 구성 가능한 속성에 따라 정리된 행들의 계층형 표가 표시됩니다. 그룹은 펼치거나 접을 수 있습니다.
3. **Dependencies(의존성):** 화살표가 관련 작업 퍽들을 연결해 순서 제약을 시각화하고 병목을 강조합니다.
4. **Detail card(상세 카드):** 퍽을 선택하면 선택한 작업의 속성을 보여 주는 상세 카드가 열립니다. 사용자는 이 화면에서 편집을 하거나 링크를 따라 이동할 수도 있습니다.

## 정리

- Program Scheduling 위젯은 프로그램, 프로젝트, 작업을 시간순 타임라인으로 보여 주며, 시작과 종료를 나타내는 날짜나 타임스탬프 속성이 있는 객체 타입이면 사용할 수 있습니다.
- 퍽은 Standard, Background(읽기 전용), Event(단일 시점) 세 종류이며 레이어마다 지정합니다.
- 의존성은 다른 객체의 기본 키를 담은 배열 속성으로 정의하고, Standard 퍽 사이의 화살표로 표시됩니다.
- 화면은 타임라인, 계층형 행 표, 의존성 화살표, 상세 카드로 구성됩니다.

# 핵심 개념 (Core concepts)

- 원문: https://www.palantir.com/docs/foundry/map/core-concepts/
- 사이드바 위치: Applications > Map > Core concepts

이 페이지는 Map 애플리케이션을 이해하는 데 필요한 세 가지 기본 개념인 레이어(layer), 객체 스타일링, 시간 선택을 정의합니다. 맵은 여러 레이어를 겹쳐 만들어지고, 각 객체의 모양은 스타일로 정해지며, 시간 선택은 어느 시점과 기간의 데이터를 보여 줄지를 정합니다.

<a id="layers"></a>
## 레이어 (Layers)

**레이어(layer)는** 맵을 만드는 데 쓰이는 지리 데이터의 모음입니다. Foundry Map 애플리케이션은 다양한 레이어를 지원하며, 이를 조합해 강력한 지리공간 시각화를 만들 수 있습니다.

* **베이스 레이어(Base layer):** 베이스 레이어는 도로, 도시, 경계선, 지명 등 세계의 지리적 특징을 그려 맵의 바탕을 제공합니다. 사용할 수 있는 베이스 레이어에는 밝은 테마, 어두운 테마, 위성 이미지 등이 있습니다. **Layers** 패널의 선택기로 베이스 레이어를 바꿀 수 있습니다.

  ![베이스 레이어 선택기](https://www.palantir.com/docs/resources/foundry/map/core-concepts-base-layer.png)

다음과 같은 다른 유형의 레이어도 사용할 수 있습니다.

* **객체 레이어(Object layer):** 온톨로지에 있는 [객체의 지리공간 데이터](07_integrate-data-for-the-map/01_integrate-objects.md)를 활용할 때 사용합니다.
* **링크 레이어(Link layer):** Search Around를 실행한 뒤 객체 사이의 관계를 보여 줍니다.
* **오버레이 레이어(Overlay layer):** [Map Layer Editor](07_integrate-data-for-the-map/05_layer-editor.md)로 고품질 시각화를 한 번만 만들어 두고, 하나 또는 여러 맵으로 가져와 사용합니다.
* **주석 레이어(Annotation layer):** 맵의 특정 영역을 강조하고 그 영역에 대한 맥락 정보를 제공하는 도형을 그립니다. [주석 만들기](04_interact-with-maps/07_annotations.md)에 대해 더 읽어 보세요.

**설명**: 레이어는 그리기 순서가 있는 투명한 도면 층입니다. 화면에는 맨 아래 베이스 레이어(지형, 도로)가 깔리고, 그 위에 객체 레이어(예: 공항 점들), 링크 레이어(공항과 활주로를 잇는 선), 주석 레이어가 차례로 그려집니다. 각 레이어를 따로 켜고 끄거나 스타일을 바꿀 수 있습니다.

> **중간 요약**: 맵은 바탕 지도인 베이스 레이어 위에 객체, 링크, 오버레이, 주석 레이어를 겹쳐 만듭니다.

<a id="object-styling"></a>
## 객체 스타일링 (Object styling)

객체에 적용하는 [스타일](06_visualize-ontology-data/01_visualize-objects.md)이 맵에서 객체의 모양을 정합니다.

<a id="time-selection"></a>
## 시간 선택 (Time selection)

모든 맵에는 **선택된 시간(selected time)** 이 있으며, 이 시간은 항상 현재 선택된 **시간 창(time window)** 안에 있습니다. 시간 창은 맵이 [시계열](05_time/05_time-series.md) 데이터를 불러와 보여 주는 기간을 정합니다. [시간 기반 스타일링](06_visualize-ontology-data/01_visualize-objects.md#opacity-styling)은 시간 선택을 이용해 시간 데이터를 가진 객체의 불투명도를 선택적으로 조절할 수 있습니다. [시간 선택](05_time/01_time-overview.md#selected-time-and-time-range) 조작에 대해 더 읽어 보세요.

**설명**: 예를 들어 시간 창이 2024년 1월 1일부터 1월 31일까지이고 선택된 시간이 1월 15일 12:00이라면, 맵은 1월 한 달치 시계열을 불러오고, 그중 1월 15일 12:00 시점의 값(예: 그 시각 선박 위치)을 기준으로 객체를 표시합니다. 시간 기반 스타일링을 쓰면 선택된 시간과 가까운 이벤트는 진하게, 먼 이벤트는 흐리게 그리는 식으로 표현할 수 있습니다.

> **중간 요약**: 스타일은 객체의 겉모양을 정하고, 시간 선택은 시간 창(불러올 기간)과 그 안의 선택된 시간(보여 줄 시점)으로 이루어집니다.

## 정리

- 레이어는 맵을 이루는 지리 데이터 묶음이며, 베이스, 객체, 링크, 오버레이, 주석 레이어가 있습니다.
- 베이스 레이어는 밝은 테마, 어두운 테마, 위성 이미지 등에서 고를 수 있습니다.
- 오버레이 레이어는 Map Layer Editor로 한 번 만들어 여러 맵에서 재사용합니다.
- 객체의 모양은 스타일로 정합니다.
- 모든 맵은 시간 창과 그 안의 선택된 시간을 가지며, 시계열 로딩 범위와 시간 기반 스타일링에 쓰입니다.

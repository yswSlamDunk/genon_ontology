# 클러스터 (Clusters)

- 원문: https://www.palantir.com/docs/foundry/map/visualize-clusters/
- 사이드바 위치: Applications > Map > Visualize Ontology data > Clusters

이 페이지는 가까이 있는 점 객체들을 하나의 원으로 묶어 보여 주는 클러스터(cluster) 디스플레이를 설명합니다. 객체가 많아 점이 서로 겹쳐 보일 때, 지역별 개수나 집계 값을 원의 크기와 색으로 나타내는 데 씁니다.

클러스터 디스플레이는 지오포인트 위치 속성(property)을 가진 큰 객체 집합(object set)에 적합합니다. 클러스터는 점과 비슷하지만, 객체마다 마커를 하나씩 찍는 대신 그려지는 객체들을 지리적 근접성에 따라 클러스터로 집계합니다. 클러스터의 크기나 색, 또는 둘 다를 설정해 주어진 영역 안의 객체 수나, 영역 안 객체들에 대한 속성 합계나 평균 같은 다른 집계 지표를 나타낼 수 있습니다. 사용자가 확대, 축소하거나 지도를 이동해 새 데이터가 들어오면 각 클러스터 영역의 내용이 자동으로 갱신됩니다.

![총 출발 항공편 수를 보여 주는 클러스터 지도.](https://www.palantir.com/docs/resources/foundry/map/cluster-example.png)

클러스터 디스플레이는 **Add geometry** 옵션으로 객체 레이어에 추가할 수 있습니다. 클러스터 디스플레이의 **Center** 설정에는 **Geopoint** 속성만 사용할 수 있습니다.

**설명**: 단계구분도가 미리 정해진 경계(주, 국가 등)로 객체를 묶는다면, 클러스터는 현재 화면에서 서로 가까이 있는 점끼리 묶습니다. 그래서 줌 레벨이 바뀌면 묶음도 바뀝니다. 예를 들어 전국 지도에서는 서울 주변 공항 3개가 클러스터 하나(개수 3)로 보이다가, 서울을 확대하면 개별 공항 3개로 나뉘어 보입니다.

<a id="styling-by-aggregation"></a>
## 집계로 스타일 지정하기 (Styling by aggregation)

클러스터 디스플레이의 스타일 옵션은 [원 지오메트리](02_visualize-points.md#circle-configuration)와 대체로 같지만, 색과 반지름 설정은 클러스터 하나에 속한 모든 객체에 대한 집계 값으로 계산됩니다. 집계 값으로 스타일을 지정하는 방법은 단계구분도 디스플레이의 [집계로 스타일 지정하기](04_visualize-choropleths.md#styling-by-aggregation) 섹션을 참고하세요.

<a id="cluster-text-labels"></a>
## 클러스터 텍스트 레이블 (Cluster text labels)

클러스터 디스플레이가 베타 개발 단계에 있는 동안, 텍스트 레이블의 내용은 색 설정에 쓰인 집계 값을 보여 주며, 색 스타일이 고정이면 반지름 설정에 쓰인 집계 값을 보여 줍니다.

## 정리

- 클러스터는 지오포인트 속성을 가진 많은 객체를 지리적으로 가까운 것끼리 묶어 하나의 원으로 그리는 디스플레이입니다.
- 원의 크기와 색은 클러스터 안 객체들의 집계 값(개수, 합계, 평균 등)으로 정하며, 확대, 축소, 이동에 따라 자동으로 다시 계산됩니다.
- **Add geometry**로 추가하고, **Center**에는 **Geopoint** 속성만 쓸 수 있습니다.
- 베타 기간 동안 레이블은 색 집계 값(색이 고정이면 반지름 집계 값)을 보여 줍니다.

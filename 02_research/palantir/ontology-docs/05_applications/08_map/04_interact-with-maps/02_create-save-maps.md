# 맵 만들기와 저장하기 (Create and save maps)

- 원문: https://www.palantir.com/docs/foundry/map/create-save-maps/
- 사이드바 위치: Applications > Map > Interact with maps > Create and save maps

이 페이지는 새 맵을 만드는 위치와, 만든 맵을 처음 저장할 때와 이후에 저장할 때의 방법을 설명합니다. 맵은 자동으로 저장되지 않으므로 저장 방법을 알아 두어야 합니다.

<a id="create-a-new-map"></a>
## 새 맵 만들기 (Create a new map)

맵을 만들려면 왼쪽의 Foundry 탐색 바를 펼친 다음 Apps 섹션에서 **View all**을 클릭합니다. **Operational Applications** 섹션 아래에서 **Map** 애플리케이션을 찾을 수 있습니다.

<img src="https://www.palantir.com/docs/resources/foundry/map/navigation-bar-map.png" alt="Foundry 탐색 바의 Map 애플리케이션" width="430" />

<a id="save-a-map"></a>
## 맵 저장하기 (Save a map)

맵을 처음 저장하려면 화면 왼쪽 위 모서리의 **Save as...** 를 클릭한 다음 맵을 저장할 위치를 선택합니다.

![Map의 Save As 버튼](https://www.palantir.com/docs/resources/foundry/map/map-overview-save-as-button.png)

그 이후에 맵을 저장하려면 화면 왼쪽 위 모서리의 **Save**를 클릭합니다. 맵은 자동으로 저장되지 않습니다.

![Map의 Save 버튼](https://www.palantir.com/docs/resources/foundry/map/map-overview-save-button.png)

**설명**: 맵은 Foundry 안에서 하나의 파일(리소스)로 저장됩니다. **Save as...** 는 프로젝트나 폴더 위치를 정해 새 리소스를 만드는 동작이고, **Save**는 이미 만들어진 그 리소스를 현재 상태로 덮어쓰는 동작입니다. 자동 저장이 없으므로 레이어나 스타일을 바꾼 뒤 **Save**를 누르지 않으면 변경 내용이 남지 않습니다.

## 정리

- 새 맵은 탐색 바의 Apps > **View all** > **Operational Applications**에서 **Map**을 열어 만듭니다.
- 처음 저장할 때는 **Save as...** 로 위치를 정하고, 이후에는 **Save**로 저장합니다.
- 맵은 자동 저장되지 않습니다.

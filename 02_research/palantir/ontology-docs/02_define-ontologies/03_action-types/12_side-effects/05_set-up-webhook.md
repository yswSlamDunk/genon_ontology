# 웹훅 설정하기 (Set up a webhook)

- 원문: https://www.palantir.com/docs/foundry/action-types/set-up-webhook/
- 사이드바 위치: Define Ontologies > Action types > Side effects > Set up a webhook

이 페이지는 기존 액션에 웹훅 규칙을 추가하는 단계별 튜토리얼입니다. 티켓 우선순위를 외부 시스템에 보내는 웹훅을 예로 들어, 라이트백과 부수 효과 중 실행 방식을 고르고, 실행할 웹훅을 선택하고, 웹훅 입력을 액션 파라미터에 매핑하는 순서를 보여 줍니다. 각 옵션의 자세한 의미는 [웹훅](04_webhooks.md) 페이지에 있습니다.

<a id="prerequisites"></a>
## 사전 준비 (Prerequisites)

1. [시작하기](../02_getting-started.md) 튜토리얼을 완료해 기본 액션을 설정하는 방법을 익힙니다.
2. 외부 시스템과 연결을 만드는 [웹훅](https://www.palantir.com/docs/foundry/data-connection/webhooks-setup/)을 설정합니다. 웹훅을 만들기 전에, 원천 시스템에 연결할 권한을 가진 시스템 관리자와 함께 작업해야 할 수도 있습니다.

<a id="steps"></a>
## 단계 (Steps)

아래 예시에서는 `priority` 문자열 값을 받아 외부 시스템으로 보내는 **Modify ticket priority**라는 웹훅이 있다고 가정합니다.

액션으로 이동해 **Logic** 탭을 선택하고, **Add new rule**을 선택한 다음 **Webhook**을 선택합니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-new-rule-webhook.png" alt="새 웹훅 추가" width="600" />

기본적으로 새로 추가된 웹훅은 **부수 효과(side effect)로** 설정됩니다. 이렇게 하면 웹훅은 Foundry에서 객체가 편집된 *후에* 실행됩니다. 대신 **Writeback**을 선택하면 웹훅이 객체 편집 *전에* 실행됩니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-writeback-or-side-effect.png" alt="라이트백 또는 부수 효과 선택" width="400" />

아래 메뉴에서 실행할 웹훅을 선택합니다. 이 예시에서는 **Modify ticket priority** 웹훅을 선택합니다. 원한다면 웹훅의 다른 버전을 선택할 수도 있습니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/webhooks-select-webhook-to-execute.png" alt="실행할 웹훅 선택" width="400" />

다음으로 액션 파라미터를 기준으로 웹훅 입력 파라미터를 설정합니다. 기본적으로 웹훅 입력마다 새 액션 파라미터가 생성됩니다. 단, 같은 이름의 액션 파라미터가 이미 있으면 그 기존 파라미터가 자동으로 설정됩니다. 이 예시에서는 `priority`라는 웹훅 입력을 `Ticket Priority`라는 기존 액션 파라미터에 매핑합니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/webhooks-input-mapping-example.png" alt="웹훅 입력을 기존 액션 파라미터에 매핑하기" width="400" />

**Add webhook**을 선택해 액션에 웹훅 규칙 추가를 완료합니다. 웹훅이 추가되면 Rules 섹션에 라이트백이 객체 수정 전에 실행된다고 표시됩니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/webhooks-add-webhook-complete.png" alt="새 웹훅 추가(완료)" width="600" />

웹훅을 추가할 때 자동 생성되었지만 이제 사용하지 않는 파라미터는 제거하는 것이 좋습니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/webhooks-remove-autogenerated-parameters.png" alt="자동 생성된 파라미터 제거" width="600" />

오른쪽 위의 **Save**를 선택해 액션 변경 사항을 저장합니다. 이제 액션이 적용되면 Foundry의 객체에 변경이 적용되기 전에 외부 시스템으로 요청이 전송됩니다.

**설명**: 원문의 마지막 단계 설명(Rules 섹션에 "라이트백이 객체 수정 전에 실행"된다고 표시되고, 저장 후 외부 요청이 객체 변경 전에 나간다는 내용)은 앞 단계에서 기본값인 부수 효과 대신 **Writeback**을 선택했다는 것을 전제로 합니다. 기본값(부수 효과)을 그대로 두었다면 요청은 객체 편집 후에 전송됩니다. 자동 생성 파라미터를 지우는 이유는, 이 예시처럼 웹훅 입력을 기존 파라미터(`Ticket Priority`)에 매핑하면 처음에 자동으로 만들어진 `priority` 파라미터가 어디에도 쓰이지 않은 채 액션 입력 양식에 남기 때문입니다.

> **중간 요약**: Logic 탭에서 Webhook 규칙을 추가하고, 부수 효과(기본값)와 라이트백 중 실행 시점을 고른 뒤, 실행할 웹훅과 버전을 선택하고 입력을 액션 파라미터에 매핑합니다. 쓰이지 않는 자동 생성 파라미터를 지우고 저장하면 완료됩니다.

## 정리

- 사전에 기본 액션과 Data Connection 웹훅이 준비되어 있어야 합니다.
- 액션의 Logic 탭에서 **Add new rule** > **Webhook**으로 웹훅 규칙을 추가합니다.
- 기본값은 부수 효과(객체 편집 후 실행)이며, **Writeback**을 고르면 객체 편집 전에 실행됩니다.
- 웹훅 입력은 같은 이름의 기존 파라미터에 자동 매핑되거나 새 파라미터로 생성되며, 사용하지 않는 자동 생성 파라미터는 지우고 저장합니다.

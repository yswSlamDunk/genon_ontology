# 섹션 구성하기 (Configure sections)

- 원문: https://www.palantir.com/docs/foundry/action-types/configure-sections/
- 사이드바 위치: Define Ontologies > Action types > Configure sections

이 페이지는 액션 폼(action form)의 파라미터를 섹션(section) 단위로 묶어 화면을 정리하는 방법을 설명합니다. 섹션을 추가하고 열 배치와 설명을 정하는 방법, 섹션에 파라미터를 넣는 두 가지 방법을 다룹니다. 파라미터가 많은 액션에서 사용자가 입력 양식을 이해하기 쉽게 만들 때 필요합니다.

액션 폼은 **섹션(section)으로** 사용자 정의할 수 있습니다. 섹션은 액션 폼을 정리하기 위해 파라미터를 논리적으로 묶어 줍니다. 섹션은 열(column), 설명, 조건부 재정의(conditional override)도 지원합니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/form-overview.png" alt="폼 개요" width="500" />

**설명**: 액션 폼은 사용자가 액션을 실행할 때 파라미터 값을 입력하는 양식입니다. HTML의 `<form>` 안에서 `<fieldset>`으로 입력 칸을 묶는 것과 같은 구조적 묶음이 섹션입니다. 조건부 재정의는 "다른 파라미터 값이 X이면 이 항목을 숨김/필수로 만듦" 같은 규칙을 말합니다.

<a id="adding-a-section-to-an-action-form"></a>
## 액션 폼에 섹션 추가하기 (Adding a section to an action form)

Form 탭에서 **Add section**을 클릭합니다. 그러면 상세한 섹션 설정 모달이 열리며, 여기서 제목을 추가하고, 열 레이아웃을 고르고, 선택적으로 사용자에게 보여 줄 설명을 작성할 수 있습니다. 설명에는 서식이 적용되지 않으며, 파라미터 설명과 달리 툴팁이 아니라 항상 섹션 안에 직접 표시됩니다.

파라미터를 열로 정리하면 폼 안의 공간을 더 잘 활용하거나 관련된 파라미터를 가까이 모아 둘 수 있습니다. 섹션은 1열 또는 2열로 나눌 수 있습니다. 폼 안에서 공간을 많이 차지하지 않는 파라미터를 사용할 때 열을 나누는 것이 특히 유용합니다.

<img src="https://www.palantir.com/docs/resources/foundry/action-types/section-config.png" alt="폼 안의 섹션" width="500" />

섹션은 접을 수 있고(collapsible), 완전히 숨길 수 있으며, 조건부 재정의를 사용할 수 있어 폼 동작을 사용자 정의할 방법이 더 많아집니다. 이 모든 기능은 섹션 안의 파라미터에도 적용됩니다. 이 기능들을 조합하면 적절한 상황에서 필요한 파라미터를 보여 주는 더 똑똑한 폼을 만들 수 있습니다. 섹션을 처음에는 숨겨 두었다가 앞선 파라미터 값에 따라서만 보여 줄 수도 있습니다.

**설명**: 예를 들어 "출장 신청" 액션에 `transport_type` 파라미터(값: 비행기, 기차)가 있다고 합시다. "항공편 정보" 섹션(항공사, 편명, 좌석 등급)을 기본으로 숨겨 두고, `transport_type`이 "비행기"일 때만 보이도록 조건부 재정의를 걸면, 섹션 안의 세 파라미터가 한꺼번에 나타나거나 사라집니다. 파라미터마다 조건을 따로 걸 필요가 없어집니다.

> **중간 요약**: Form 탭의 **Add section**으로 제목, 1열 또는 2열 레이아웃, 항상 보이는 설명을 가진 섹션을 만듭니다. 섹션의 접기, 숨기기, 조건부 재정의는 안에 든 파라미터 전체에 적용됩니다.

<a id="adding-parameters-to-a-section"></a>
## 섹션에 파라미터 추가하기 (Adding parameters to a section)

섹션에 파라미터를 추가하는 방법은 섹션 설정 화면에서 추가하는 방법과 **Form** 탭에서 추가하는 방법 두 가지입니다.

섹션 설정 화면에서 **Add new parameter**를 클릭합니다. 여기서 새로 추가된 파라미터를 섹션 안에서 설정합니다. 또는 **Add existing parameter**를 클릭해 기존 파라미터를 섹션으로 옮길 수 있습니다.

**Form** 탭은 섹션과 그 안의 파라미터를 하나의 개요로 나열합니다. 파라미터 왼쪽의 점 여덟 개(드래그 핸들)를 클릭해 기존 섹션으로 끌어다 놓습니다. 파라미터와 섹션은 이 **Form Content** 영역에서의 순서대로 폼에 표시됩니다.

> **중간 요약**: 섹션 설정 화면의 **Add new parameter** 또는 **Add existing parameter**, 또는 Form 탭에서 드래그로 파라미터를 섹션에 넣으며, 폼의 표시 순서는 Form Content 목록의 순서를 따릅니다.

## 정리

- 섹션은 액션 폼의 파라미터를 논리적으로 묶는 단위이며 제목, 열(1열 또는 2열), 설명을 가집니다.
- 섹션 설명은 툴팁이 아니라 섹션 안에 항상 표시됩니다.
- 섹션은 접기, 숨기기, 조건부 재정의를 지원하며 그 효과는 안의 파라미터 전체에 적용됩니다.
- 파라미터는 섹션 설정 화면에서 새로 만들거나 기존 것을 옮기거나, Form 탭에서 드래그해 넣을 수 있습니다.

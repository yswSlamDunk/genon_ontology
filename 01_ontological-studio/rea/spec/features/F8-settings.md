## 1. 목적
앱 안의 설정 화면에서 다음을 정하고 확인한다 [결정 대기 D-13 — 권장안 "만든다"로 작성].
1. 어떤 **에이전트 백엔드**(Claude Code / Codex / 내장)로 구축·질의할지, 지금 상태는 어떤지
2. **LLM 공급자·키·모델**(내장 에이전트와 코어의 단일 LLM 클라이언트가 씀)
3. **외부 MCP** 공개 여부와 **개인 접근 토큰**(범위·만료)
4. 데이터 폴더·로그·포트·프로세스 **정보**
5. **보안 스위치**(에이전트 셸 도구, 콘솔 Cypher 쓰기, SQL Function)
6. **예제 데이터 초기화**
7. 옛 `studio.env` 방식의 **가져오기/내보내기**와 고급 파일 설정

## 2. 원본 기준 동작 요약 [원본]
근거: 분석 `menus/08-settings/design.md` §1–§9.
- 앱 안에 설정 화면이 **없다**. 홈 「설정」 카드(설명 `studio.env — 에이전트 · LLM 키.`)는 데이터 폴더의 `studio.env`를 **OS 기본 앱으로 연다**(REVIEW #10).
- 에이전트만 메뉴 「런타임 › 에이전트」 라디오(Claude Code / Codex / 내장 에이전트 (OpenAI 호환 키))로 바꿀 수 있다 → 파일 갱신 → Studio 두 프로세스 재시작. 「(설치 안 됨)」 표시는 앱 시작·전환 때만 다시 계산.
- 홈 상태 줄(그래프 연결, 에이전트 준비/사용할 수 없음 + 안내 문구 + 「설정」 버튼), 카드 배지(「에이전트 설정 필요」, 「별도 서비스」).
- `studio.env`: 줄 단위 `KEY=VALUE`, 빈 값 = 없음, 따옴표 한 쌍 제거, 인라인 주석 미처리, 뒤 키 우선, 권한 0600. 키: `AGENT_BACKEND`, `EXTERNAL_AGENT_ID`, `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `MAJOR_MODEL`, `MINOR_MODEL`, `KINETIC_*`, `MCP_ALLOW_DATASOURCE_EXPANSION` 외 다수(§5.5). 앱이 정하는 값은 덮어쓸 수 없음.
- 파일 변경은 **앱 재시작** 때 반영. 알 수 없는 키·잘못된 줄은 조용히 무시.
- 비밀값(LLM 키)이 평문 파일에 있고, 등록 시스템 비밀은 파일로 넣을 수 없음(REVIEW #11).

## 5. 화면 구성과 상호작용

### 5.1 레이아웃
- 탭 제목 「설정」. 왼쪽 섹션 목록, 오른쪽 내용. 섹션: **에이전트 · LLM · 외부 연결(MCP·토큰) · 보안 · 데이터·저장소 · 예제 데이터 · 가져오기/내보내기 · 정보**.
- 섹션 목록에 상태 점(예: 에이전트 미준비면 노랑, 외부 MCP 켜짐이면 파랑).
- 각 항목 오른쪽에 적용 방식 표시: 「즉시」 / 「다음 턴부터」 / 「다시 시작 필요」(§5.10 표).
- 값이 고급 고정 파일(§5.8)로 정해져 있으면 항목 잠금 + 「파일로 고정됨: <파일 이름>」.
- 주소: `view=settings&section=<id>` (상태 줄 「설정」 버튼은 `section=agent`).

### 5.2 에이전트
- **백엔드 선택**(라디오, 원본 메뉴와 같은 라벨): `Claude Code` / `Codex` / `내장 에이전트`. 미설치 CLI는 `(설치 안 됨)` + 비활성(원본). 「다시 찾기」 버튼(C5).
- **상태 카드**(원본 결정 표를 그대로 표시, A3 §4.3):
  - 굵게: 표시 이름 또는 `사용할 수 없음`, 점 초록/노랑(원본 규칙)
  - 안내 문구(원본 문구 유지, 단 `studio.env 에 OPENAI_API_KEY 를 넣으세요`는 「설정 › LLM에서 키를 넣으세요」로 바꿈):
    - `` `<cli>` 를 찾지 못해 내장 에이전트로 실행합니다. <표시 이름> 를 설치하면 다음 시작부터 씁니다.`` → 「…설치한 뒤 「다시 찾기」를 누르세요.」 (재시작 불필요로 바뀜)
    - `` `<cli>` 를 찾지 못했고 LLM 키도 없습니다. <표시 이름> 를 설치하거나 설정 › LLM에서 키를 넣으세요.``
  - 세부: CLI 경로·버전(`claude --version` 결과) [확인 필요: 로그인 상태 확인 방법], 요청값 vs 실제값(원본에서 "체크는 요청값 기준" 혼란 → 둘 다 표시: 「선택: Claude Code · 실행 중: 내장 에이전트」).
- **CLI 실행 옵션**(04 §7 반영, 읽기 전용 표시 + 일부 스위치): 허용 도구 목록 보기, 작업 폴더 밖 쓰기 금지(항상 켬, 표시만), 사용자 전역 설정 차단(항상 켬, 표시만), 턴 시간 제한(기본 1800초, 원본 값).
- **전환 동작**: 선택 즉시 Agent 모듈 재초기화(C4). 진행 중 턴이 있으면 대화상자 「진행 중인 대화 N개가 있습니다. 끝날 때까지 기다릴까요, 지금 중단할까요?」. 완료 후 상태 카드 갱신, 홈 상태·배지 갱신(원본: 전환 끝날 때 다시 그림).
- 원본과 같이 열린 탭의 대화 이어짐(CLI 세션 id)은 백엔드가 바뀌면 끊긴다 — 안내 「다른 에이전트로 바꾸면 진행 중인 대화는 새로 시작됩니다.」

### 5.3 LLM
- **공급자**: `OpenAI 호환`(기본, 원본과 같음) / `Anthropic` / `로컬(Ollama 등 OpenAI 호환 주소)`. 공급자별 칸:
  - 기본 주소(base URL) — 원본 `OPENAI_BASE_URL`. 원본처럼 "키 없이 주소만 있어도 설정됨"으로 본다(로컬 모델).
  - API 키 — 키체인. 입력칸은 항상 비어 있고 저장돼 있으면 `저장됨 · …a1b2` + 「바꾸기」·「지우기」.
- **모델**: 「큰 모델」(원본 `MAJOR_MODEL`, 기본 원본 값) / 「작은 모델」(`MINOR_MODEL`) / 각 추론 강도(`none|low|medium|high`, 기본 medium). 입력 형식 `provider:model` 또는 `model`(원본 규칙). 「모델 목록 불러오기」(공급자가 목록 API를 주면).
- **임베딩**: 모델(원본 기본 `openai:text-embedding-3-small`), 또는 로컬 주소(원본 `OLLAMA_BASE_URL`, `OLLAMA_EMBEDDING_MODEL`). 원본의 "base URL이 있으면 임베딩은 자동으로 Ollama" 암묵 규칙은 **명시 선택**으로 바꿈(의도된 차이).
- **문서 OCR 모델**(v1, D-15 ⑤): 원본 `OCR_MODEL` 대응.
- 「연결 시험」: 작은 모델로 짧은 요청 1회 → `✓ 응답 <s> · <모델>` 또는 오류(인증 실패/주소 없음/모델 없음 번역).
- **사용처 표**(C6, 읽기 전용):

| 기능 | 무엇을 쓰나 |
|---|---|
| 구축·질의·액션·대시보드 대화 | 선택한 에이전트(CLI면 CLI 자체 모델, 내장이면 큰/작은 모델) |
| 브리프 초안·답변·액션 계획(내장) | 작은 모델 |
| 그래프 콘솔 자연어→Cypher | 선택한 에이전트의 단발 호출(내장이면 작은 모델) |
| 품질 추출(F6), 위젯 추천(F5), Function LLM형 | 단일 LLM 클라이언트(작은 모델) — **CLI만 있고 키가 없으면 CLI 단발 호출로** [제안] |
| 임베딩·벡터 검색 | 임베딩 설정 |
- 값 바꾸면 「다음 호출부터」 적용(재시작 없음).

### 5.4 외부 연결 (MCP · 토큰)
- **외부 MCP 공개** 스위치(기본 끔). 켤 때 네이티브 확인 창(§9). 켜져 있으면 주소 표시 `http://127.0.0.1:<web>/mcp/external` + 「복사」.
- **개인 접근 토큰** 표: 이름 · 범위 · 만든 날 · 마지막 사용 · 만료 · 상태(유효/만료/폐기) · 「폐기」.
  - 「토큰 만들기」 대화상자: 이름(필수, 1–40자), 범위 체크(03 §3·04 §8): `read`(온톨로지 지도·Object set, live 값 제외), `data`(live 원천 값 포함 — 원본 `MCP_ALLOW_DATASOURCE_EXPANSION`의 후계), `plan`(액션 계획 요청까지; 승인은 사람만). 만료: 7일 / 30일(기본) / 90일 / 직접(최대 1년). "만료 없음" 없음.
  - 만들기 → 네이티브 확인 창 → 토큰 값을 **한 번만** 보여 줌(복사 버튼, 「이 창을 닫으면 다시 볼 수 없습니다」). 저장은 해시만.
  - 클라이언트 설정 스니펫 복사(MCP 클라이언트용 JSON: url + `Authorization: Bearer` 헤더 자리).
- 토큰이 0개이거나 외부 MCP가 꺼져 있으면 `/mcp/external`은 401/404(03 §11-8).
- 「앱 SDK 토큰」(코드 앱별, F5)은 여기서 목록만 보여 주고 관리 링크는 F5로 [제안].

### 5.5 보안 (고급)
위험 안내를 머리에 둔다: 「아래 스위치는 사람의 확인 없이 일어날 수 있는 일을 늘립니다. 필요할 때만 켜세요.」 모든 스위치 기본 끔, 켤 때 네이티브 확인 창, 끄는 것은 즉시(확인 없음).

| 스위치 | 효과 | 결정 | 적용 |
|---|---|---|---|
| **구축 모드에서 셸 명령 허용** | build 모드 CLI 턴에 Bash(작업 폴더 안) 허용, 내장 에이전트 `execute` 허용. 켜도 **각 대화의 첫 셸 사용 때** 화면에 「이 대화에서 에이전트가 셸 명령을 쓰려 합니다」 허용/거부(대화 단위 동의) | D-10 권장안 "build만 동의 시" | 다음 턴부터 |
| **그래프 콘솔 Cypher 쓰기** | F4 연습 그래프 쓰기 허용(발행 관리 그래프는 여전히 거부) | D-20 | 즉시 |
| **SQL Function(고급)** | Function `query` 종류에서 SQL 직접 본문 허용(원본 behavior 계승). 발행 검증 시 단일 SELECT·읽기 역할 강제 | D-07 | 다음 발행부터 |
| **에이전트 도구: 읽기 전용 Cypher** | `cypher_readonly` 도구를 answer/act 모드에 추가(04 §5 "고급, 설정으로 켬") | 04 §5 | 다음 턴부터 |
- 각 스위치 옆 「마지막 변경: <시각> · <사람>」(감사에서).

### 5.6 데이터·저장소 (정보 + 일부 설정)
- 데이터 폴더 경로·크기, 「데이터 폴더 열기」(원본 동작). 다른 폴더로 실행하는 방법 안내(환경 변수, P §7.1).
- 로그 폴더, 「로그 폴더 열기」, 구성 요소별 로그 파일 목록·크기·「보기」(마지막 500줄, 비밀 마스킹 후).
- **포트 표**: 구성(게이트웨이·앱 오리진·PG·Bolt·코어·예제 서비스) · 현재 포트 · 선호 포트 · 출처(환경 변수/지난번/선호/OS 임의). 「선호 포트 바꾸기」(다시 시작 필요).
- **프로세스 표**(상태 API, P §8): 이름 · PID · 상태 · 시작 시각 · 재시작 횟수.
- 부팅 시간 기록(마지막 부팅 단계별 ms, 원본 형식).
- 「백업 만들기」(v1 [제안]): PG 논리 덤프(메타·런타임·감사 + 예제 DB, 원천 비밀 제외) + 업로드·코드 앱 폴더를 압축 하나로. 복원은 새 데이터 폴더에서만.

### 5.7 예제 데이터
- 예제 설치 상태: 예제 업무 서비스(erp·wms·crm) 켬/끔(끄면 프로세스를 띄우지 않음, 다시 시작 필요), 예제 데이터소스 3, 예제 시스템 3(F7), 예제 온톨로지.
- **「예제 데이터 초기화」** 범위 체크:
  - 예제 업무 DB 행(erp·wms·crm 스키마를 첫 실행 상태로 — 액션으로 바뀐 priority 등 되돌림)
  - 예제 데이터소스·`sample` 그래프 가상 타입 재등록(원본 "예제 패브릭 초기화" 규칙, A2 §6.4)
  - 예제 시스템 등록(F7)
  - 예제 온톨로지(작업본·발행본·편집 레이어·액션 실행 기록) — 기본 해제(사용자 작업이 섞여 있을 수 있음)
- 실행 전 네이티브 확인 창(「예제 데이터를 첫 실행 상태로 되돌립니다. 사용자 데이터소스·온톨로지는 건드리지 않습니다.」). 사용자 데이터에는 영향 없음(원본 A2 §6.4 원칙).

### 5.8 가져오기/내보내기 · 고급 파일
- **studio.env 가져오기**(N7): 파일 선택 → 원본 읽기 규칙(원본 design §5.2: `KEY=VALUE`, 대문자 키, 빈 값 무시, 따옴표 한 쌍 제거, 인라인 주석 미처리, 뒤 키 우선)으로 파싱 → 미리보기 표 `키 | 값(비밀은 ••••) | 처리`:

| 원본 키 | 처리 |
|---|---|
| `AGENT_BACKEND`, `EXTERNAL_AGENT_ID` | 에이전트 선택 |
| `OPENAI_API_KEY` | 키체인(LLM 키) |
| `OPENAI_BASE_URL`, `MAJOR_MODEL`, `MINOR_MODEL`, `*_REASONING_EFFORT`, `OCR_*`, `OLLAMA_*`, `QUALITY_EXTRACT_MODEL`, `EMBEDDING_CHUNK_MAX_TOKENS` | LLM 설정 |
| `MCP_MAX_RESULTS`, `MCP_MAX_EXCERPT_CHARS`, `DATASOURCE_MAX_ROWS`, `DATASOURCE_AGENT_ROW_PREVIEW`, `AGENT_HISTORY_MAX_TOKENS` | 고급 한도(§5.9) |
| `MCP_ALLOW_DATASOURCE_EXPANSION` | **적용 안 함** — 「외부 MCP는 토큰 범위 `data`로 대체되었습니다」 |
| `KINETIC_*` | 적용 안 함 — 「액션 실행기는 내장되었습니다」 |
| 앱이 정하는 키(원본 §5.6 목록) | 무시 — 「앱이 정함」 |
| 그 밖 | 무시 — 「알 수 없는 키」 |
  - 「적용」 → 설정 반영 + 비밀은 키체인. 원본 파일은 건드리지 않음.
- **내보내기**(N8): `settings.env`(같은 `KEY=VALUE` 형식, 원본 키 이름 유지할 수 있는 것은 원본 이름). 비밀은 `# OPENAI_API_KEY=  (키체인에 있음)` 주석 줄. 개인 접근 토큰은 내보내지 않음.
- **고급 고정 파일** [제안]: 데이터 폴더의 `override.env`(없으면 무시). 부팅 때 읽어 같은 키의 설정을 **고정**(화면에서 잠금). 비밀 키(`*_API_KEY`, `*_TOKEN`, `*_PASSWORD`)는 이 파일에서 받지 않음(「비밀값은 파일에 넣을 수 없습니다」 경고 로그). 용도: 여러 기기 같은 설정 배포, 자동화 테스트. 권한 0600이 아니면 읽지 않고 경고.

### 5.9 고급 한도 (접힘)
원본 `studio.env`로만 바꿀 수 있던 값 중 쓸모 있는 것: 에이전트 도구 결과 행 상한(30), 데이터소스 최대 행(500), MCP 결과 수(20)·발췌 길이(500), 대화 기록 토큰 상한(48000), 턴 시간 제한(1800초), 콘솔 결과 상한(1,000행·30초). 기본값은 원본 값. 「기본값으로」.

## 6. API
코어 `/api/v1`, 세션 토큰 필수. **권한을 넓히는 쓰기**(§9 표)는 요청 헤더 `X-Approval-Proof`(셸이 발급한 증표, 03 §4) 필수.

| 메서드 | 경로 | 요청 | 응답 |
|---|---|---|---|
| GET | `/settings` | — | `{agent, llm, mcp, security, limits, samples, restartPending:[key], lockedByFile:[key]}` (비밀은 `{set: bool, last4}`만) |
| PATCH | `/settings` | 부분 객체 | 갱신된 전체 + `applied: {key: immediate|nextCall|restart}` |
| PUT | `/settings/secrets/{name}` | `{value}` (`llm.apiKey` 등) | `{set:true, last4}` — 쓰기 전용, 읽기 API 없음 |
| DELETE | `/settings/secrets/{name}` | — | `{set:false}` |
| POST | `/settings/llm/test` | `{provider?, baseUrl?, model?}`(생략 시 저장값) | `{ok, model, latencyMs, error?}` |
| GET | `/agent/status` | — | 원본 `info().agent` 형태 `{backend, agentId, label, ready, note}` + `requested`, `cli:{claude:{path, version}|null, codex:…}` |
| POST | `/agent/detect` | — | 위와 같음(CLI 재탐지) |
| POST | `/agent/switch` | `{to: "claude-code"|"codex"|"builtin", onRunning: "wait"|"abort"}` | `{status, agent}` |
| GET/POST | `/settings/tokens` | POST `{name, scopes[], expiresInDays}` | POST: `{id, token(1회), expiresAt}` |
| DELETE | `/settings/tokens/{id}` | — | `{revoked:true}` |
| POST | `/settings/samples/reset` | `{scopes:[db, fabric, systems, ontology]}` | `{jobId}` → 진행은 `/api/v1/events` |
| POST | `/settings/import-env` | `multipart file` 또는 `{text}`, `dryRun` | `{items:[{key, action, note}]}` |
| GET | `/settings/export-env` | — | `text/plain` |
| GET | `/system/status` | — | P §8 상태 API |
- 원본 셸 `info()`의 `llmConfigured`(= agent.ready), `kineticConfigured`는 셸 정보 API에 호환 필드로 남긴다(P §5.4 배지 계산용). `kineticConfigured`는 항상 `true`(실행기 내장) — 「별도 서비스」 배지는 사라짐.
- 설정 변경 알림: `/api/v1/events`의 `settings` 토픽(홈 상태·배지·열린 화면 갱신).

## 7. 데이터
- **Settings**(코어 `workbench.runtime.settings`, 키-값 JSON, 버전 열):
```yaml
agent:    { requested: claude-code | codex | builtin, turnTimeoutSec: 1800 }
llm:      { provider: openai-compatible | anthropic | local, baseUrl, apiKeyRef,
            majorModel, minorModel, majorEffort, minorEffort,
            embedding: { mode: provider | local, model, baseUrl? }, ocrModel }
mcp:      { externalEnabled: false }
security: { agentShellInBuild: false, consoleCypherWrite: false, sqlFunctions: false, agentCypherReadonly: false }
limits:   { agentToolRows: 30, datasourceMaxRows: 500, mcpMaxResults: 20, mcpExcerptChars: 500,
            agentHistoryTokens: 48000, consoleRows: 1000, consoleTimeoutSec: 30 }
samples:  { servicesEnabled: true }
```
- **셸 설정 파일**(데이터 폴더, 부팅 전 필요): `shell-settings.json` `{preferredPorts:{…}, samplesEnabled}` 0600. 포트 결과는 원본처럼 `ports.json`.
- **PersonalAccessToken** `{id, name, scopes, tokenHash(argon2/sha256+salt), createdAt, lastUsedAt, expiresAt, revokedAt, createdBy}` — `workbench.runtime`.
- **비밀**: 키체인 항목 `<제품>/<데이터 폴더 id>/llm/apiKey` 등, `workbench.secret_ref`에 참조.
- 설정 변경 이력은 감사(`workbench.audit`, `kind: settings.change`, 이전·새 값 — 비밀은 `set/unset`만).

## 8. 에이전트 연동
- 어떤 모드에도 설정 읽기·쓰기 도구는 **없다**. 에이전트가 "LLM 키를 바꿔 줘" 같은 요청을 받으면 설정 화면 링크를 안내하도록 지시문에 명시(F1·F2 지시문 공통 규칙) [제안].
- 에이전트 실행에 설정이 반영되는 방식: 백엔드 선택(04 §2), 셸 도구 스위치 → CLI `--allowedTools`에 Bash 포함 여부(04 §7), 읽기 전용 Cypher 도구 노출, 한도 값 → 도구 결과 상한.
- CLI 프로세스 환경에는 설정값을 넘기지 않는다(03 §5 화이트리스트). LLM 키도 넘기지 않음 — CLI는 자기 로그인을 씀.

## 9. 보안·권한
- 설정 화면·API는 **사람 UI 세션**만(세션 토큰 쿠키). 개인 접근 토큰·앱 SDK 토큰·턴별 MCP 토큰으로는 `/settings*`, `/agent/switch` 접근 403.
- **승인 증표가 필요한 변경**(03 §4 네이티브 확인 창):

| 변경 | 창에 보이는 내용 |
|---|---|
| 외부 MCP 켬 | 「외부 AI 클라이언트가 토큰으로 온톨로지에 접근할 수 있게 됩니다.」 |
| 토큰 발급 | 토큰 이름·범위·만료 |
| 보안 스위치 켬(4종) | 스위치 이름과 효과 한 줄 |
| 예제 데이터 초기화 | 범위 목록 |
| 고급 한도를 기본값의 10배 넘게 올림 | 항목과 값 [제안] |
- 끄기·폐기·줄이기는 증표 없이(권한을 좁히는 방향).
- 비밀: 화면·API·로그·내보내기 어디에도 평문 없음. 키 입력칸은 `autocomplete=off`, 붙여넣기 후 메모리에서 바로 전송.
- 가져오기 파일은 읽기만 하고 원본 파일을 지우거나 고치지 않는다. 가져오기 뒤 「원본 studio.env에 키가 평문으로 남아 있습니다. 지우시겠습니까?」 안내(삭제는 사용자가 직접).
- `override.env`는 0600이 아니면 무시(원본 0600 정책 계승), 비밀 키는 받지 않음.

## 10. 오류·예외
| 상황 | 표시 | 원본 대비 |
|---|---|---|
| CLI 없음 + 키 없음 | 홈 `에이전트 사용할 수 없음` + 「설정」 + 카드 배지 「에이전트 설정 필요」(원본 문구). 앱은 계속 동작 | 같음(안내 문구 일부 변경) |
| 내장 선택 + 키·주소 없음 | 상태 카드 「내장 에이전트를 쓰려면 LLM 키 또는 주소가 필요합니다.」 + LLM 섹션 링크 (원본: `AGENT_BACKEND=deepagents 인데 LLM 접속 정보(OPENAI_API_KEY 또는 OPENAI_BASE_URL)가 비어 있습니다.`) | 문구 변경 |
| 연결 시험 실패 | 인증 실패 「키가 맞지 않습니다(401).」 / 주소 오류 「주소에 접속하지 못했습니다.」 / 모델 없음 「모델 <m> 을(를) 찾지 못했습니다.」 | 신규 |
| 전환 중 진행 턴 | 대화상자(§5.2) | 원본: 전환 중 요청 무시 |
| 전환 실패 | 상태 카드 빨강 + 오류, 이전 백엔드 유지, 로그 `agent switch failed: …`(원본 로그 문구) | 비슷 |
| 키체인 접근 거부 | 「OS 키체인에 저장하지 못했습니다. 접근을 허용한 뒤 다시 시도하세요.」 | 신규 |
| 승인 창 취소 | 스위치 원위치, 변경 없음 | 신규 |
| 증표 없는 권한 확대 요청(API 직접 호출) | 403 `{error:"approval proof required"}` | 신규 |
| 가져오기 파일 형식 오류 줄 | 미리보기에 「무시됨(형식 아님)」 — 원본처럼 조용히 버리지 않고 보여 줌 | 변경 |
| `override.env` 권한·비밀 키 | 시작 로그 경고 + 설정 화면 머리 경고 | 신규 |
| 예제 초기화 중 실패 | 단계별 결과(성공/실패) 표, 실패 단계만 「다시 시도」 | 신규 |

## 11. 원본과 비교할 테스트
**같아야 함**
1. 에이전트 결정 표 다섯 경우의 `agent` 값(`backend`·`label`·`ready`·`note` 구조)과 홈 상태 줄 점 색·굵은 글씨(안내 문구는 바뀐 부분 제외).
2. 메뉴 「런타임 › 에이전트」 라벨·활성 규칙(미설치 `(설치 안 됨)` 비활성).
3. 카드 배지 「에이전트 설정 필요」 조건(`llmConfigured === false`)과 다시 그리는 시점.
4. 「로그 폴더 열기」·「데이터 폴더 열기」가 같은 폴더를 연다.
5. studio.env 가져오기의 파싱 규칙이 원본 읽기 규칙(design §5.2)과 같다: 빈 값 무시, 따옴표 한 쌍 제거, 인라인 주석 미처리, 소문자 키 무시, 뒤 키 우선.
6. 기본 모델·추론 강도·한도 값이 원본 기본값과 같다.

**의도된 차이 (D-12)**
1. 「설정」 카드가 파일 대신 설정 탭을 연다(D-13). 카드 설명 `studio.env — 에이전트 · LLM 키.` → `에이전트 · LLM · 외부 연결 · 보안.`
2. LLM 키가 키체인에 있고 파일·DB 덤프에 평문 없음.
3. 에이전트 전환에 프로세스 재시작 없음, CLI 설치 후 「다시 찾기」로 즉시 반영.
4. 외부 MCP 기본 끔, 토큰 필요(원본: 실데이터 확장 기본 켬·무인증). `MCP_ALLOW_DATASOURCE_EXPANSION` → 토큰 범위 `data`.
5. `KINETIC_*` 없음, 「별도 서비스」 배지 없음.
6. 권한 확대 변경에 네이티브 확인 창.
7. 임베딩 공급자 명시 선택(원본: base URL 있으면 암묵적으로 Ollama).

## 12. 열린 질문
1. CLI 로그인 상태(Claude Code/Codex 인증 여부)를 확인할 공식 방법이 있는가 [확인 필요]. 없으면 "설치됨"만 표시하고 첫 턴 실패 시 안내.
2. CLI만 있고 키가 없을 때 품질 추출·위젯 추천을 CLI 단발 호출로 돌릴지(§5.3 표) — 04 §3 단일 클라이언트의 범위 정의 필요.
3. 고급 고정 파일(`override.env`)이 필요한가, 가져오기/내보내기만으로 충분한가.
4. 설정 자체의 백업·이전(다른 기기): 내보내기 파일 + 키 재입력으로 충분한가.
5. 1인 사용 전제에서 "설정 변경 이력"을 화면에 둘지(감사로 충분한지).
6. 예제 업무 서비스를 "선택 설치"(01 §2.1)로 할 때, 설치 안 된 경우 이 섹션의 표시.

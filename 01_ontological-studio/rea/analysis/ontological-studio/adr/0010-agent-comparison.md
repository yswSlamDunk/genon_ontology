# ADR-0010 에이전트 기능은 구조·계약 수준으로 기록·비교
- 상태: 승인 (2026-10-31, 사용자)
## 맥락
M1 구축·M2 질의·액션·M5 온톨로지 앱은 LLM이 결과를 만들어 원본도 실행마다 결과가 다르다.
## 결정
이 메뉴들의 원본 동작 기록과 이후 비교는 **결과 내용이 아니라 구조·계약**을 기준으로 한다:
흐름(단계 순서), API 호출과 요청·응답 형식, 생성되는 데이터의 형태(스키마), 상태 변화, 오류·승인 처리.
시나리오당 1회 기록을 기본으로 한다(Claude Code 사용량 절약).
## 결과
`baseline/`에는 원본 응답 내용도 저장하되, 비교 항목(design.md)은 구조·계약 기준으로 적는다.

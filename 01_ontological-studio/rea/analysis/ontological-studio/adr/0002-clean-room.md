# ADR-0002 구현은 클린룸 방식
- 상태: 승인 (2026-10-31, 사용자)
## 맥락
본체 저장소 `uengine-oss/ontology-studio`에는 라이선스가 없다(소스 공개이지만 권리 유보). `ontological-db`는 Apache-2.0, `cliagents`는 MIT 표기.
## 결정
설계 문서에는 **동작과 인터페이스**(화면, API, 데이터 모델, 시나리오)만 쓰고, 본체 코드는 복사하지 않는다. 구현은 설계 문서를 보고 새로 작성한다.
## 결과
- 설계 문서에 원본 코드 블록을 붙이지 않는다(근거는 `파일:줄` 참조로만).
- Apache-2.0/MIT 부분을 쓸 경우 그 라이선스 조건을 따른다.
- 제품화 시 유엔진에 라이선스 확인 권장(법률 판단 아님).

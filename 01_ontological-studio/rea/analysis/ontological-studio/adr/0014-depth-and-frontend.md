# ADR-0014 분석 깊이 기준과 프런트엔드 근거
- 상태: 승인 (2026-10-31, Claude 결정 — 사용자 이의 시 변경)
## 결정
- **깊이 기준:** 사용자가 보는 동작, API, 데이터 모델까지가 기본. 내부 알고리즘은 결과를 좌우하는 경우에만 깊이 본다(예: nl2cypher 프롬프트·검증, 품질 판정 규칙, 액션 승인 흐름).
- **프런트엔드:** 화면 7개가 압축 번들 하나(`index-Bnym06ph.js`, 2.3MB, 소스맵 없음)라, 실행 기록에서 얻은 API 목록과 화면 캡처를 주 근거로 삼고 번들 정적 분석(REA)은 확인용으로 쓴다.

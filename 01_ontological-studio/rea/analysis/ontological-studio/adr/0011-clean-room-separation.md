# ADR-0011 구현은 설계 문서만 받은 별도 세션이 수행
- 상태: 승인 (2026-10-31, 사용자)
## 맥락
분석하는 Claude가 원본 코드를 깊이 읽으므로, 같은 주체가 구현하면 엄밀한 클린룸이 아니다(ADR-0002 보강).
## 결정
구현은 **원본을 보지 않은 별도 세션/에이전트**가 `design.md`(와 baseline의 구조·계약 정보)만 보고 수행한다.
## 결과 (분석 단계에 미치는 영향)
- `design.md`는 그것만으로 구현할 수 있을 만큼 자기완결적으로 쓴다.
- `design.md`에는 원본 코드·식별자 나열을 넣지 않는다. 원본 위치 근거는 별도 `code-trace.md`에 두고 구현 세션에는 넘기지 않는다.

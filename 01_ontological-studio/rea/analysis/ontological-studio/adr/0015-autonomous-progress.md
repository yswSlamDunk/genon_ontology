# ADR-0015 중간 검토 없이 자율 진행, 사후 일괄 검토
- 상태: 승인 (2026-10-31, 사용자) — ADR-0013 대체
## 맥락
사용자가 자리를 비우는 동안(수면) 검토 대기로 진행이 멈추면 안 된다.
## 결정
- 대상별 사용자 검토 지점(1단계 후·5단계 후)을 두지 않는다. Claude가 판단해 끝까지 진행한다.
- 진행 중 필요한 결정은 Claude가 내리고 ADR(상태 `승인(Claude)`)로 남긴다.
- 사용자는 나중에 `REVIEW.md`(검토할 것·Claude가 내린 결정·열린 질문 모음)를 보고 일괄 검토한다.
## 결과
- 사용자 확인이 꼭 필요한 사항은 진행을 막지 않고 `REVIEW.md`에 쌓은 뒤, 안전한 기본값으로 진행한다.
- 되돌리기 어렵거나 외부에 영향을 주는 행동은 하지 않는다(앱 실행 기록은 ADR-0004 범위 안에서만).

# ADR-0005 분석 단위: 공통 기반 3 + 사용자 메뉴
- 상태: 승인 (2026-10-31, 사용자)
## 맥락
구현 모듈 기준 지도(Claude)와 사용자 메뉴 기준 목록(사용자)이 있었다. 모듈 지도는 메인 프로세스만 보고 만들어 불완전했고(품질 검수 누락), 원본 비교는 사용자 메뉴 단위로 일어난다.
## 결정
- 먼저 **공통 기반** A1 셸·부팅·프로세스 / A2 저장소(PostgreSQL+Bolt) / A3 에이전트·MCP를 한 번 분석한다.
- 그다음 **사용자 메뉴**를 하나씩 심층 분석한다. 메뉴 목록은 배포본 기준으로 `feature-map.md`에서 확정한다.
- 메뉴 ↔ 모듈 ↔ 근거 추적 표를 `feature-map.md`에 둔다.
## 비고
사용자가 체감한 8개 메뉴: 온톨로지 구축, 질의·액션, 데이터소스, Ontological Portal, 온톨로지 앱, 품질 검수, 시스템 등록, 설정.
2026-10-31 확인: 이 8개는 배포본 홈 화면 카드(`shell.js` CARDS)와 정확히 일치한다. Studio 내비게이션의 「대시보드」는 「온톨로지 앱」 카드가 여는 화면(`view=board`)이라 별도 메뉴가 아니다. 메뉴 목록 확정.

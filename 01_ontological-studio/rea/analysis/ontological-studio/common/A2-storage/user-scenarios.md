# A2 저장소 — 운영 시나리오

- 상태: 초안 (2026-10-31, 정적 분석)
- 출처: 배포본 0.1.1 Electron 셸 코드, 번들 리소스(`resources/sample`), 사용자 기존 데이터 폴더의 로그(2026-10-28 첫 실행, 2026-10-31 재실행 기록 — 사용자가 이전에 실행한 결과, 이번 분석에서 실행하지 않음)
- 공통 기반이므로 사용자 메뉴 시나리오가 아니라 **앱 첫 실행·재실행·종료·데이터 폴더 이전** 같은 운영 시나리오로 짧게 쓴다.
- 기준 버전: 0.1.1 (ADR-0012)

## 공통 사전 상태
- 4단계 기록은 ADR-0004에 따라 `ONTOLOGICAL_STUDIO_USER_DATA=<analysis 하위 전용 폴더>`로 띄운다.
- 시나리오별로 데이터 폴더 전후 목록(`ls -la`, `pgdata` 안 숨김 파일), `logs/desktop.log`, `logs/postgres.log`, `logs/bolt.log`, `ports.json`, `secrets.json`의 **키 목록만**(값은 기록 금지)을 남긴다.

---

## S1. 첫 실행 (빈 데이터 폴더)
- **목적:** 저장소가 처음 만들어지는 과정과 결과 상태를 확인한다.
- **단계:**
  1. 비어 있는(또는 없는) 분석용 데이터 폴더를 지정해 앱을 띄운다.
  2. 시작 화면의 단계 표시가 「준비 완료」가 될 때까지 기다린다.
- **기대 결과 (코드·기존 로그):**
  - 시작 화면 단계 문구: `PostgreSQL 시작` → `첫 실행 — Ontological 확장과 예제 DB 준비` → `Ontological Bolt 게이트웨이 · 포털 시작` → `Studio · 키네틱 액션 · 예제 시스템 시작` → `예제 온톨로지 · 액션 준비 (첫 실행)` → `준비 완료`
  - 데이터 폴더에 `pgdata/`, `run/`, `logs/`, `ports.json`, `secrets.json`(권한 600), `studio.env` 생성
  - 포트는 선호값 그대로(PostgreSQL 27432, Bolt 27687 …), 사용 중이면 임의 포트
  - DB: `ogstudio`(그래프 `ontology`, 추상 루트 타입 `_Entity`), `sample`(스키마 `erp`·`wms`·`crm`)
  - 패브릭: 데이터소스 `erp`(테이블 6), `wms`(3), `crm`(4), 그래프 `sample`에 가상 노드 7·가상 관계 5
  - 기존 로그 실측 소요: PostgreSQL 준비 ~0.9초, 부트스트랩 ~0.24초, 전체 UI 로드 ~5초
- **기록할 것:** 단계 문구 화면 캡처, 생성된 파일 목록과 권한, `psql`로 DB·역할·확장 목록(`\l`, `\du`, `\dx`), `SHOW GRAPHS`·`SHOW DATASOURCES` 결과, `boot-timings.json`
- **주의:** 첫 실행은 예제 온톨로지 생성(Studio 스크립트)까지 포함한다. 임베딩 서버가 없으면 경고가 찍혀도 계속 진행된다(기존 로그에서 관찰).

## S2. 재실행 (정상 종료 뒤)
- **목적:** 이미 준비된 저장소를 다시 쓰는지(재초기화하지 않는지) 확인한다.
- **단계:**
  1. S1 후 앱을 정상 종료한다.
  2. 같은 데이터 폴더로 다시 띄운다.
- **기대 결과:**
  - 부트스트랩·예제 적재 단계 문구가 **나오지 않는다**
  - `ports.json`의 포트를 그대로 다시 쓴다
  - 기존 로그 실측: PostgreSQL ~0.5초, UI 로드 ~3.1초
- **기록할 것:** 단계 문구, `desktop.log` 줄 수, 포트 변화 여부, 그래프·데이터소스 상태가 S1과 같은지

## S3. 재실행 — 선호 포트가 다른 프로그램에 점유된 경우
- **목적:** PostgreSQL 포트가 바뀌었을 때 예제 데이터소스가 새 포트로 다시 등록되는지 본다.
- **단계:**
  1. 앱을 종료한 뒤, 다른 프로그램으로 `127.0.0.1:27432`를 점유한다(예: `nc -l 127.0.0.1 27432`).
  2. 앱을 다시 띄운다.
- **기대 결과:**
  - PostgreSQL이 임의 포트로 뜨고 `ports.json`이 갱신된다
  - 로그: `PostgreSQL 포트가 27432 → <새 포트> 로 바뀌어 예제 데이터소스를 다시 등록합니다`
  - 예제 데이터소스·가상 노드가 지워졌다가 다시 만들어진다
- **기록할 것:** 로그, 재등록 뒤 데이터소스 미리보기가 되는지, 사용자가 직접 만든 데이터소스(있다면)는 어떻게 되는지
- **주의:** 사용자가 만든 데이터소스는 재등록 대상이 아니다 → 옛 포트를 가리킨 채 남을 수 있음(모르는 점)

## S4. 종료
- **목적:** 프로세스가 정해진 순서로 멈추고 DB가 깨끗이 닫히는지 확인한다.
- **단계:** 메뉴 또는 트레이에서 종료한다(창을 모두 닫아도 종료).
- **기대 결과:**
  - `desktop.log`: `shutdown` → `all stopped`
  - 순서: 앱 서비스(Studio·MCP·kinetic·예제 서비스) → 포털·Bolt → PostgreSQL(빠른 종료)
  - `run/*.pid`가 모두 지워지고 `pgdata/postmaster.pid`가 없다
  - 다음 시작 때 `postgres.log`에 복구(recovery) 메시지가 없다
- **기록할 것:** 종료 소요 시간, 남은 프로세스(`ps`), pid 파일 유무

## S5. 비정상 종료 후 재실행
- **목적:** 강제 종료로 남은 프로세스·잠금 파일을 정리하는지 본다.
- **단계:**
  1. 앱 실행 중 Electron 메인 프로세스만 `kill -9` 한다(자식 프로세스는 남음).
  2. 앱을 다시 띄운다.
- **기대 결과:**
  - `desktop.log`: `orphan <이름>.pid (pid N) — stopping` (이전 실행이 남긴 자식 정리)
  - PostgreSQL이 정상 기동(필요하면 WAL 복구)
- **기록할 것:** 정리된 프로세스 목록, 복구 로그
- **주의:** 분석용 데이터 폴더에서만. 실패 시 폴더를 버리고 다시 만든다.

## S6. 데이터 폴더 지정과 이전 이름 폴더 이전
- **목적:** 데이터 폴더가 어디로 정해지는지 확인한다.
- **경우:**
  1. 환경 변수 `ONTOLOGICAL_STUDIO_USER_DATA`(또는 옛 이름 `ONTOLOGY_LITE_USER_DATA`)가 있으면 그 폴더를 쓴다. 이전 처리는 하지 않는다.
  2. 없으면 OS 기본 위치(macOS: `~/Library/Application Support/Ontological Studio`). 옛 앱 이름 폴더(`Ontology Studio Lite`)에 DB가 있고 새 폴더에 DB가 없으면 → 옛 폴더를 새 이름으로 옮긴다.
  3. 옛 폴더의 PostgreSQL이 아직 실행 중이면 옮기지 않고 옛 폴더를 그대로 쓴다.
- **기대 결과:** `desktop.log` 첫 줄에 이전 결과 문구(`데이터 폴더를 새 이름으로 옮겼습니다: …` 등)
- **기록할 것:** (선택) 임시 HOME 없이 재현이 어려우므로 4단계에서는 1번만 확인. 2·3번은 코드 근거로 둔다.
- **참고:** 같은 데이터 폴더로는 하나만 실행된다(두 번째 실행은 첫 창을 앞으로). 다른 데이터 폴더라면 동시에 실행 가능하고 포트는 각자 잡는다.

## S7. 외부 도구로 저장소 접속 (관찰용)
- **목적:** 비교·검증 때 원본 저장소를 직접 들여다보는 방법을 확인한다.
- **단계:**
  1. `ports.json`에서 `pg`, `bolt` 포트를 읽는다.
  2. `psql -h 127.0.0.1 -p <pg> -U og -d ogstudio` (비밀번호는 `secrets.json`의 PostgreSQL 비밀번호)
  3. Neo4j 드라이버/`cypher-shell`로 `bolt://127.0.0.1:<bolt>`, 사용자 `og`, 같은 비밀번호, 데이터베이스 `ontology` 또는 `sample`
- **기대 결과:** 두 경로 모두 같은 그래프를 보여 준다. Bolt 서버 문자열은 `Neo4j/4.4.0 (ontological-bolt)`
- **기록할 것:** 메뉴 사이 스냅샷용 `pg_dump` 명령이 동작하는지(ADR-0009), Bolt 접속 시 협상 버전
